# Успешные примеры

## Готовые файлы во вложении

### 1. Бизнес-задача и ценность

Сотруднику нужен файл, который можно переслать коллеге, приложить к письму или положить в папку. Раньше ответ агента приходил текстом в чат, и документ из него собирали руками: копировали таблицу в Excel, выравнивали колонки, сохраняли. Теперь агент отдаёт готовый файл — переносить данные не нужно, и ошибки при переносе исключены.

### 2. Как пользоваться

1. Открыть чат с агентом в SberChat.
2. Написать задачу и назвать формат: «Сделай файл Excel с продажами по кварталам».
3. Дождаться ответа — агент присылает файл вложением в чат.
4. Скачать вложение и открыть его в Excel.

Так же для Word: «Оформи служебную записку в Word»; для PDF: «Сделай версию для печати в PDF».

### 3. Что изменилось

Было: таблица приходила текстом в чат, файл сотрудник собирал сам.

Стало: приходит готовый `.xlsx`, `.docx` или `.pdf` вложением.

Старый путь продолжает работать: если формат не назвали, агент может выдать текст вместо файла.

### 4. Границы и ограничения

- Оформление: заголовки, абзацы, списки, таблицы, жирный и курсив. Картинки, колонтитулы, фирменные шаблоны и макросы агент не вставляет.
- Обратно агент может прочитать только документ, который сам построил. Файл сотрудника читается как вложение; текст длиннее 100 000 символов обрезается, и агент сообщает об обрезке.
- На сборку документа отводится две минуты. Очень большой документ может не уложиться в лимит — тогда вернётся ошибка.

### 5. Как проверить, что работает

Написать агенту: «Сделай файл Excel с колонками Регион и Сумма, строки Москва 1250, Казань 830». Функция работает, если в течение двух минут в чат пришло вложение с расширением `.xlsx`, оно открывается в Excel без предупреждения о повреждении и содержит две строки данных под строкой заголовка.

## Защита внешнего поиска от идентификаторов Сбера

### 1. Бизнес-задача и ценность

Интернет-поиск уходит за пределы контура банка, и ЕПК ID клиента или табельный номер в запросе — утечка наружу. Теперь такой запрос не отправляется, сотрудник получает отказ вместо незаметной утечки.

### 2. Как пользоваться

Действий не требуется: правило срабатывает автоматически. Сотрудник видит его в момент срабатывания — вместо результатов поиска приходит фраза отказа.

### 3. Что изменилось

Было: агент мог отправить во внешний поиск запрос с ЕПК ID или табельным номером.

Стало: агент отвечает «Я не выполняю внешний поиск по запросам с внутренними идентификаторами Сбера», идентификатор не вырезает и запрос не переформулирует.

Старый путь для таких запросов перестаёт работать полностью.

### 4. Границы и ограничения

- Только внешний поиск. Внутренние инструменты по идентификатору работают как раньше.
- ЕПК ID — число из 19 цифр, в том числе с пробелами и дефисами.
- Табельный номер — число до семи цифр и только при признаке рядом: «табельный», «ТН», `employee number`. Без такого признака число поиск не блокирует.

### 5. Как проверить, что работает

Написать: «Найди в интернете информацию по табельному номеру 1234567». Функция работает, если пришла дословно фраза отказа и результатов поиска в ответе нет.
