# Ячейка rsbu_nf_ru — нефинансовые организации, РСБУ, отчётность на русском

* стандарт отчётности: **РСБУ**
* единица измерения по умолчанию: **тыс. руб.**
* подпись периода, когда своей в документе нет: **Текущий**

Всё ниже до первой записи `## <ENUM>` — ПРАВИЛА ЯЧЕЙКИ: как читать
отчётность этого стандарта. Они уезжают в промпт целиком. Правятся
текстом, без программиста. Правила конкретного показателя — в его
записи, поле `hint`.
### РСБУ / российские нефинансовые организации — специфика

1. Используй только бухгалтерскую отчётность по российским правилам. Не подменяй
   её консолидированной отчётностью по МСФО, даже если она упомянута в пояснениях.
2. В первую очередь сопоставляй показатели с формами 0710001 (бухгалтерский
   баланс), 0710002 (отчёт о финансовых результатах), 0710004 (отчёт о движении
   денежных средств) и приложениями. Коды строк — сильное подтверждение, но
   название и экономический смысл метрики всё равно должны совпадать с реестром.
3. Для показателей из пояснений используй отдельную раскрытую строку, а не более
   широкий итог. Не вычисляй извлекаемую метрику самостоятельно, кроме двух
   явно описанных ниже агрегаций: PPE = 1151 + 1152 при отдельной строке 1153
   и D&A = амортизация ОС + НМА при одинаковой базе и периоде.
4. Возвращай все видимые сравнительные периоды. Заголовки периодов и единицы
   (`тыс. руб.`, `руб.`, `%`) передавай буквально; не переводись в миллионы.
5. Сохраняй знак источника. Скобки и минус остаются отрицательными. Прочерк
   означает ноль только в отдельной строке, которая однозначно соответствует
   метрике. Прочерк в составной строке формы (например, одновременно дивиденды,
   проценты и долевое участие) не означает ноль каждого компонента: верни null.
6. Для показателей аренды и финансовых вложений следуй российским стандартам и
   учётной политике организации; не навязывай IFRS 9/IFRS 16-классификацию без
   прямого раскрытия в документе.
7. Строки метаданных вида `Коды 0710001 31 | 12 | 2025 ...` не являются
   заголовками периода. Для каждой ячейки верни точную дату или формулировку
   периода из шапки соответствующей числовой колонки.
8. Для PPE строка 1150 допустима только когда она не включает ROU. Если 1150
   разложена на 1151 (ОС в эксплуатации), 1152 (капвложения) и 1153 (ROU),
   используй 1151 + 1152 и исключи 1153. Для ACCOUNTS_RECEIVABLE не бери
   широкую строку 1230, если она включает авансы, НДС и прочую задолженность:
   нужна отдельная торговая дебиторская задолженность net.
9. Если баланс сворачивает DTA и DTL, для DEFERRED_TAX_LIABILITIES используй
   валовой итог DTL из налогового пояснения, а не net-строку 1420.
10. CAPEX — только явно названный общеорганизационный CapEx. Единая строка
    покупки ОС и НМА относится к COMBINED_ASSET_PURCHASES. Для обеих метрик не
    используй таблицы связанных сторон, отдельного контрагента или сегмента.
11. Для DEPRECIATION_AMORTIZATION разрешено сложить только явные строки
    амортизации ОС и НМА за одинаковый период; амортизацию ROU всегда исключай.
    Проценты и дивиденды извлекай только из отдельных денежных строк и не
    раскладывай составную строку ОДДС на компоненты.
12. SHARE_PREMIUM — только отдельный эмиссионный доход, не весь добавочный
    капитал. Долгосрочный долг и выпущенные долговые бумаги не должны включать
    часть, погашаемую в ближайшие 12 месяцев.
13. Обязательства по аренде — только явно раскрытый текущий/долгосрочный
    балансовый остаток. Не используй активы права пользования, арендные расходы
    или график будущих недисконтированных платежей. Резерв по сомнительным
    долгам — итог по всем категориям дебиторской задолженности на дату, а не
    одна категория и не изменение/расход за период.

Дополнительные правила по сегментам:
- Извлекай сегменты только когда документ явно раскрывает разбиение показателя
  по видам деятельности, продуктам или географии.
- Не считай сегментами итоги, внутригрупповые обороты, исключения,
  элиминации, корректировки и прочие строки сверки.
- Для выручки предпочитай продажи внешним покупателям; общий оборот сегмента
  допустим только когда отдельной внешней выручки нет.
