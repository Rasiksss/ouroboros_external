## Когда

Нужна величина, которой в таблице нет. Путей расчёта три — какой брать,
решает оглавление ячейки (шаг 1 «Порядка работы»):

1. **Реестровая формула** — показатель есть в секции «Расчётные» оглавления.
   Путь по умолчанию: считает движок по формуле методолога, с единицей,
   знаком и проверкой диапазона.
2. **Своя формула** — показателя в «Расчётных» нет, но он записывается ОДНИМ
   арифметическим выражением из реестровых величин.
3. **Скрипт** — выражением не записать: нужна степень, цикл или условие
   (дисконтирование, NPV, IRR, CAGR, сценарии, чувствительность), либо
   пользователь просит произвольный счёт, не привязанный к отчёту.

## Что нужно на входе

**1. Файл набора величин** — вход `--in` (путь к файлу). Формат:

```json
{"metrics": [
  {"enum": "NET_INCOME",    "value_current": 100.0,  "found": true},
  {"enum": "SALES_REVENUE", "value_current": 1000.0, "found": true}
]}
```

Откуда взять файл — три случая:

| Ситуация | Что делать |
|---|---|
| В этом ходе шло извлечение | файл уже лежит: `./metrics.json`; ячейка записана внутри него |
| Числа назвал пользователь | создай файл сам по формату выше; имена — реестровые (по оглавлению); добавь `--cell` |
| Чистая арифметика, величины не нужны («посчитай 2+2», «NPV по моим ставкам») | файл НЕ нужен: сразу путь 3 — `--script` без `--in` |

Числа, взятые из разговора, не имеют страницы-источника в отчёте — укажи это
в ответе одной фразой.

**2. Ячейка реестра** — из файла извлечения читается сама; для ручного файла — флаг `--cell`.

## Если входа нет

Нужных величин нет ни в файле, ни в разговоре — считать не из чего. Перечисли
недостающие в ответе ПОИМЁННО: их даёт извлечение или сам пользователь.

## Порядок работы

1. **Определи путь расчёта по оглавлению ячейки.** Прочитай его целиком:
   `cat .shelf/aifa_station_skills/aifa-extract/method/catalogue/_index_<ячейка>.md`
   Для выбора пути нужна секция **«Расчётные (формула)»**: заказанный
   показатель там есть — путь 1, возьми его имя (ENUM). Нет, но выражается
   формулой из величин секции «Извлекаемые» — путь 2 (имена входов бери
   ровно оттуда). Не выражается формулой — путь 3.
2. **Подготовь входной файл** — по таблице раздела «Что нужно на входе».
3. **Для пути 2 — файл со своей формулой, для пути 3 — файл-скрипт** —
   подразделы ниже.
4. **Запусти расчёт:**
   `bash .shelf/aifa_station_skills/aifa-calc/run.sh --in ./metrics.json --only NET_DEBT`

   Параметры (в одном вызове совместимы любые):
   * `--in <путь>` — входной файл набора величин; обязателен всегда, кроме
     чистого счёта скриптом. Он же выход: посчитанные строки дописываются в
     него (отдельный файл результата — `--out-json <путь>`);
   * `--only <имена>` — считать ТОЛЬКО перечисленные показатели (ENUM через
     запятую, из шага 1). Обязателен во всех случаях, кроме просьбы «посчитай
     ВСЕ коэффициенты»: без него движок перебирает все формулы ячейки и на
     точечный вопрос возвращает десятки пустых строк. Перечисляй только сам
     показатель: промежуточные величины его формулы движок рассчитает
     автоматически (заказал `NET_DEBT` — `TOTAL_DEBT` посчитается сам);
   * `--cell <ячейка>` — только для файла, составленного вручную: файл
     извлечения ячейку уже несёт;
   * `--extra-calculated <файл>` — файл своей формулы (путь 2);
   * `--script <файл>` — файл скрипта (путь 3); имя файла без каталогов —
     команда исполняется уже в рабочей папке, где ты его создал;
   * `--final` — только когда расчёт закрывает прогон: хвостом извлечения
     нонс приходит сам; отдельный вызов с `--final` требует переменной
     `FE_PROGRESS_NONCE=<НОНС>` (нонс выдаёт система) — без неё ни таблицы,
     ни Excel.
5. **Прочитай вывод**: сводка «посчитано N, пропущено M» и причина у каждой
   пропущенной строки — что значит каждая причина, в разделе «Вывод».

### Путь 2: своя формула (`--extra-calculated`)

JSON-список записей — формат тот же, что в навыке извлечения:
`[{"enum":"ИМЯ_ЛАТИНИЦЕЙ", "name_ru":"как зовут", "formula":"A / (B - C) * 100", "deps":["A","B","C"], "unit_kind":"percent|ratio|days"}]`

* имена в формуле — реестровые, все они же в `deps`;
* функции — только `ABS, MIN, MAX, AVG, ANNUAL`; знак расходных статей:
  движок берёт их по модулю — в формуле ВЫЧИТАЙ (`… - CAPEX`);
* дни и год — `DAYS_IN_PERIOD` и `ANNUAL(...)`, не числа руками;
* проверки смысла у своей формулы нет — на порядок величины смотри сам;
* о том, что показателя в реестре не было и формула твоя, — скажи в ответе.

### Путь 3: скрипт (`--script`)

Создай файл в рабочей папке (`cat > model.py`), передай `--script model.py`.
Перед ПЕРВЫМ скриптом прочитай целиком
`.shelf/aifa_station_skills/aifa-calc/method/расчёт-скриптом.md`: какие данные
уже поданы скрипту, как вернуть строки таблицы (контракт `RESULT`) и как
позвать готовый реестровый коэффициент, не выводя его заново.

Параметры, которых нет в отчёте (ставка дисконтирования, темп роста,
горизонт), выбираешь ты — перечисли выбранные значения в ответе рядом с
результатом. Скрипт упал — прочитай traceback, поправь и запусти снова: файл
в комнате между вызовами живёт.

## Правила

**Запрещено считать самому.** Каждое число даёт код: движок или твой скрипт.
В уме не считай, «для проверки» не пересчитывай, числа из PDF руками не
переписывай. Результат кажется неверным — скажи в ответе, но не подменяй.

**Запрещено выдавать неполное за полное.** Строка не посчиталась — назови в
ответе причину и недостающий вход поимённо («FCF не посчитан: нет CAPEX»).
Ноль, прочерк и «около» вместо числа запрещены.

**Запрещено переопределять реестр молча.** Определения реестра не
переписывай; просят по другой базе — возьми реестровую формулу, поправь
названное и укажи в ответе, что именно изменил. Подмена показателя похожим
разрешена, только если она видна в имени («…по операционной прибыли вместо
EBIT») и названа первой фразой ответа.

Показателя нет в реестре — считать всё равно надо, но методику выбирает
аналитик: определений несколько — перечисли их в ответе и спроси; посчитал по
своему выбору — укажи рядом с числом, какое определение взял.

## Вывод

Сводку из stdout отдай как есть: посчитано N, пропущено M. Причины
пропущенных строк и что с ними делать:

| Причина в строке | Что это значит | Что делать |
|---|---|---|
| `не заказывали` | величины нет во входном файле | добудь: извлечением или у пользователя |
| `искали, в отчёте НЕТ` | извлечение искало и не нашло — переизвлечение не поможет | перепиши формулу под доступные входы, указав это в ответе, либо честно «не считается» и почему |
| `рыночная величина` | цена, курс, число акций — в отчёте не бывает | спроси у пользователя или возьми из его слов |

Полную таблицу не печатай — её рисует система. Отдельный расчёт — покажи
только запрошенные строки: показатель, значение, единица, чем посчитано;
считал скриптом — рядом выбранные параметры. Инструмент упал — покажи текст
ошибки и остановись.

## Границы навыка

| Просят | Это не сюда |
|---|---|
| «извлеки показатели из отчёта» | извлечение — навык `aifa-extract` |
| «сделай выводы», «что с компанией» | разбор — навык `aifa-analyze` |
| «добавь показатель в набор навсегда» | правка реестра ячейки, а не расчёт |
| «построй график» | не этот навык |
