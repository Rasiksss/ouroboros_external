## Когда

Только внутренний/совместимый вызов с уже известным
`intent_kind=full_analysis`. Обычный текст пользователя направляй в
`aifa-metric`: там обязательно выполняется настоящий `intent.parse`.

Нужен полный или краткий финансовый вывод по одному уже извлечённому отчёту.
Производитель отчёта всегда один: `Target(ReportOutput) → ProducerResolver →
PlanGraph → EvidenceBundleV2 → Judgment/Explanation → NarrativeOutput →
verify.grounding/verify.citation → ReportOutput`.

## Что нужно на входе

Извлечение показателей этого документа уже прошло раньше (навык извлечения) —
`--metrics` называет путь к его typed manifest, доказательство завершённого
ingress. Дальше нужны: `--text` (OCR, доставляется обёрткой), `--depth`,
`--docs` (ровно один document id).

## Если входа нет

Извлечения этого документа ещё не было — сначала запусти навык извлечения,
здесь начинать нечего: числа для анализа берутся из его typed-результата, не
из свободного текста. `--analysis-type`/`--lens` не назвали — работают
значения по умолчанию (`general`, без призм).

## Порядок работы

`FE_PROGRESS_NONCE=<нонс> bash .shelf/aifa_station_skills/aifa-analyze/scripts/analyze_run.sh --text ./ocr-<doc_id>.txt --metrics ./metrics.json --cell <ячейка> --docs <doc_id> --depth <full|quick>`

Флаги:

- `--depth full|quick` — глубина вывода.
- `--analysis-type general` — вид анализа; неподдержанное значение не
  подменяется `general` молча, а получает отказ.
- `--company-type bank|non_financial` — только явное переопределение
  пользователя.
- `--lens credit,risk` — список призм методики.
- `--docs` — ровно один document id; несколько документов навык отклонит.

Таблица призм — единственное декларативное место включения. Пустая таблица
означает, что ни одна призма пока не объявлена:

## Правила

Сырой текст доступен только атомам чтения графа — не пересчитывай числа сам
и не восстанавливай их из markdown. Если граф или проверка заземления
отказала, отдай typed-отказ дальше как есть; не запускай параллельный старый
разбор и не подменяй отказ пересказом.

## Вывод

Источник истины — typed `ReportOutput` в durable Case/SSE; stdout — только
presentation-рендер того же результата. Не переписывай числа и не пересказывай
markdown как новый результат.

## Границы навыка

Не для точечного извлечения показателей — за этим отдельный навык. Не для
отчёта, у которого извлечение ещё не пройдено этим ходом.
