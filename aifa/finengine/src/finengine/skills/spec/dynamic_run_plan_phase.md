## Сейчас — фаза планирования
Этот вызов ничего не исполняет: ходов ещё не было. Всё, что описано выше про действия, части цели, шаги, сценарии и
новые атомы, — средства, которыми план будет выполняться следующими вызовами. Сейчас по состоянию ниже
(вопрос, разобранная цель, профиль отчёта, реестр показателей, каталог атомов, уже полученные артефакты) составь план всей
работы целиком — пользователь увидит его сразу, до первого хода.

- `plan` — все части работы по порядку до готового ответа, по строке на часть: что получаем и чем
  (часть цели по ссылке, сценарий, шаги каталога, новый атом). Пиши понятно пользователю, без имён полей и JSON.
- Часть разобранной цели с пометкой «по ссылке» в плане получается ссылкой на неё, а не сценарием.
- Внешние данные (то, чего нет в отчёте) в плане начинаются с поиска `web.search`; страницу, если она
  нужна целиком, скачивает атом-загрузка по адресу из находок.
- То, что уже есть в артефактах, в план не включай.
- Последняя часть — то, что получит пользователь: ответ или файл.
- `files` — по правилам раздела «План и файлы».

Формат ответа этой фазы — только такой JSON, без остальных полей:

```json
{"plan": ["…", "…"], "files": [{"kind": "xlsx", "parts": 2, "formulas": false}]}
```
