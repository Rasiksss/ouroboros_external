# Финансовый анализ

## Когда
Пользователь просит ВЫВОДЫ / ОЦЕНКУ по приложенному отчёту. «Быстро/коротко» — это
всё равно анализ, просто короче, НЕ «только цифры».

## Что делать — выбери ГЛУБИНУ по смыслу
- По умолчанию: **`fe_analyze(doc_id, depth='full')`** — полный структурированный
  отчёт по разделам с таблицами (один проход модели по ТЕКСТУ отчёта).
- Когда просят «быстро / коротко / в двух словах»:
  **`fe_analyze(doc_id, depth='quick')`** — сжатая выжимка + ключевые коэффициенты
  с флагами (норма/внимание/риск).

Тип компании (банк / нефинансовая), стандарт (МСФО/US GAAP) и язык определяются
автоматически по тексту отчёта — не выбирай и не спрашивай. Роль в анализе НЕ
участвует (это ось только для извлечения показателей).
Если вернётся «text not ready» — сначала `fe_idp_ocr(doc_id)`, затем повтори.

## Вывод
Выведи `report_markdown` из ответа тула ПОЛНОСТЬЮ, без сокращений. НЕ считай и не
дополняй показатели вручную — анализ уже заземлён на текст отчёта.
