# agent-workspace/skills — MCP-профиль навыков (деливерабл для нативного OpenCLAW)

SKILL.md-паки для **нативного** гейтвея OpenCLAW (банковский контур Расула):
навык учит агента звать наши **fe_* MCP-тулы** (fe_analyze, fe_extract_metrics,
factor_analysis, kb_*). Скриптов здесь нет — вся логика на стороне MCP-сервиса.

**На нашем dev-VPS этот каталог НЕ потребляется** (наш чат-путь исполняет тулы
инлайн в бэкенде). Это упаковка возможностей finengine для чужого нативного
стека — см. #49/#50.

**Не путать со `station-skills/`** (**exec-профиль**): там SKILL.md несёт рядом
сам движок (`scripts/*.py`) и исполняется через `exec` в Workstation-станции —
и он ЖИВОЙ (копируется в образы backend и станции).

⚠️ **Дрейф-риск (#72):** имена навыков пересекаются (aifa-analyze /
aifa-extract*). Меняя семантику навыка (параметры, depth/role, контракт
вывода) — правь ОБА профиля; регрессию #76 чинили в двух местах.
