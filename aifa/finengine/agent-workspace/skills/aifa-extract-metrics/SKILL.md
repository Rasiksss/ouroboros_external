# Извлечение показателей

## Когда
Пользователь просит САМИ ЦИФРЫ по приложенному отчёту (без выводов/оценки). Если
просят «проведи анализ / сделай выводы / оцени» — это НЕ сюда, это `fe_analyze`
(навык **aifa-analyze**).

## Что делать
Один вызов: **`fe_extract_metrics(doc_id)`**.
- `company_type` и период определяются автоматически — не спрашивай.
- `role` не передавай, если пользователь не назвал роль (other/risks/baifp/die/cib/dgr) —
  UI уже прокидывает выбранную роль.
- Если вернётся «text not ready» — сначала `fe_idp_ocr(doc_id)`, затем повтори.

## Вывод
- Выведи `table_markdown` ПОЛНОСТЬЮ — все строки, без сокращений и «…».
- Над таблицей ОДНА строка: компания · ячейка `cell` · период `main_period` · единицы `unit`
  (бери именно `main_period`, не выдумывай год).
- Если есть `excel_file_id` — под таблицей: «📎 Полная версия по всем периодам — Excel в Источниках».
- НЕ добавляй строки «Источник: …», не пересчитывай числа вручную.
