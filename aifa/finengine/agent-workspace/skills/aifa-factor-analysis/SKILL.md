# Факторный (план-факт) анализ

## Когда
В Источниках проекта есть xlsx план и факт, и пользователь просит разложить
отклонение по факторам («почему упала маржа», «что изменилось», «по факторам»).

## Что делать
1. Один вызов: **`factor_analysis(period_label='Q1 2026')`** — план и факт находятся
   по именам файлов автоматически (не спрашивай file_id).
2. Дефолтный ответ (без явной просьбы о деталях):
   - 1 строка-заголовок: «Q1 2026: выручка +1.6%, маржа −X% (−Y млн ₽)»
   - **3 маржинальных фактора** в МЛН ₽
   - 1–2 предложения интерпретации + продукт-драйвер
   - Финал: «📎 Детализация в Excel: <имя файла из `xlsx_artifact`>»

## Follow-up («как посчитал», «формула фактора X», «по продуктам»)
НЕ перезапускай `factor_analysis`. Найди в истории результат
`[Tool result: factor_analysis]` и процитируй формулы/числа ОТТУДА.

## Не делай
Без Python-кода с расчётами; без `read_source` для перепарсинга xlsx; без ручной
правки чисел; не проси file_id (автоопределение работает).
