# База знаний чата

## Когда пользователь вставил ссылку
Вызови **`kb_add_url(url=…)`** — НЕ `fetch_url`. `kb_add_url` сохраняет источник в
ПОСТОЯННУЮ базу знаний ЭТОГО чата (а `fetch_url` — разовый показ без сохранения).

## Follow-up по добавленному
Вызови **`kb_search(query=…)`** — вернёт релевантные фрагменты с источниками.
Отвечай со ссылкой: «Согласно [источник](url): …».

## Если ссылка пришла из дайджеста/календаря
URL уже в markdown результата — извлеки его сам и пройди тем же путём
(`kb_add_url` → `kb_search`), не проси ссылку у пользователя.
