# Контракт API GigaSearch (v3)

## Общая информация

- **Метод:** `POST`
- **Эндпоинт:** `/v3/search`

---

## Заголовки запроса (Headers)

| Поле           | Тип     | Кратность | Nullable | Описание                |
| -------------- | ------- | --------- | -------- | ----------------------- |
| `X-Request-ID` | string  | 1         | 0        | ID запроса              |
| `X-Surface-ID` | string  | 1         | 0        | ID поверхности          |
| `X-User-ID`    | string  | 1         | 0        | ID пользователя         |

---

## Тело запроса (Body)

| Поле          | Тип           | Кратность | Nullable | Ограничения / Доп. информация                                                                 |
| ------------- | ------------- | --------- | -------- | --------------------------------------------------------------------------------------------- |
| `query`       | string        | 1         | 0        | Текст запроса. Длина от 1 до 2048 символов.                                                   |
| `limit`       | int           | 0–1       | 0        | Количество документов в выдаче. Значение по умолчанию: 10. Диапазон: 1–100.                   |
| `search_mode` | string        | 0–1       | 0        | Режим поиска: `"fast"` (до 1 сек) или `"advanced"` (по умолчанию).                            |
| `scopes`      | array[string] | 0–N       | 1        | Источники для поиска (например, `"web"`, `"facts"`, `"news"`). Если не указаны — все источники. |
| `filters`     | array         | 0–N       | 1        | Дополнительные фильтры (опционально).                                                         |

---

## Тело успешного ответа (Body)

```json
{
  "documents": [
    {
      "id": "id",
      "title": "",
      "content": "",
      "url": "",
      "scope": ""
    }
  ],
  "search_metadata": {
    "status": "ok/warning/error",
    "code": "200",
    "description": "статус"
  }
}
```

### Поля `documents`

| Поле      | Тип    | Кратность         | Nullable | Описание                       |
| --------- | ------ | ------------------- | -------- | ------------------------------ |
| `id`      | string | 1 (если есть docs) | 0        | ID контекста                   |
| `title`   | string | 1 (если есть docs) | 0        | Заголовок контекста            |
| `content` | string | 1 (если есть docs) | 0        | Содержимое контекста           |
| `url`     | string | 0–1               | 1        | Ссылка на исходный документ    |
| `scope`   | string | 0–1               | 0        | Источник поиска                |

> **Примечание:** При ошибках 4xx или 5xx поле `documents` отсутствует.

### Поля `search_metadata`

| Поле          | Тип    | Кратность | Nullable | Описание                                                                                          |
| ------------- | ------ | --------- | -------- | ------------------------------------------------------------------------------------------------- |
| `status`      | string | 1         | 0        | Текстовый статус: `"ok"`, `"warning"`, `"error"`                                                  |
| `code`        | string | 1         | 0        | Код ответа (например, `"200"`)                                                                   |
| `description` | string | 0–1       | 1        | Техническое описание статуса. Заполняется только при `warning` или `error` (см. правила ниже).   |

#### Правила заполнения `description`

| Статус     | Код     | Условие                                                           | Значение `description`                                                                                  |
| ---------- | ------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `ok`       | `200`   | Успешный запрос                                                   | Пустая строка                                                                                           |
| `warning`  | `200`   | Не отработал один из указанных источников                         | `"No data was retrieved from [имя_источника]"`                                                         |
| `error`    | `4xx` / `5xx` | Запрос не выполнен, ошибка клиента или сервера                   | Текстовое описание ошибки (например, текст из ответа)                                                  |

---

## Ответ при ошибке (Body)

При возникновении ошибок 4xx или 5xx:

- Поле `documents` отсутствует.
- В `search_metadata`:
  - `status` = `"error"`
  - `code` = соответствующий HTTP-код (например, `"400"`, `"500"`)
  - `description` содержит текстовое описание ошибки.
