# Показатели реестра: общее для всех профилей отчёта

Реестр зависит от профиля отчёта (стандарт, тип компании, язык). Здесь — только показатели, которые есть в каждом профиле. Полный список для отчёта этого хода — раздел «Реестр показателей» в ответе `aifa_state`: верь ему, а не этому файлу.

- ifrs_nf_ru — тип компании non_financial; извлекаемых 77, рассчитываемых 51
- ifrs_bank_ru — тип компании bank; извлекаемых 80, рассчитываемых 33
- rsbu_nf_ru — тип компании non_financial; извлекаемых 62, рассчитываемых 34
- rsbu_bank_ru — тип компании bank; извлекаемых 49, рассчитываемых 11
- us_gaap_nf_en — тип компании non_financial; извлекаемых 77, рассчитываемых 51
- us_gaap_bank_en — тип компании bank; извлекаемых 62, рассчитываемых 28
- ifrs_nf_en — тип компании non_financial; извлекаемых 77, рассчитываемых 51
- ifrs_bank_en — тип компании bank; извлекаемых 80, рассчитываемых 32
- ind_as_nf_en — тип компании non_financial; извлекаемых 74, рассчитываемых 50

## Извлекаются во всех профилях (читаются из отчёта, если строка в нём есть)
- MODIFIED_AUDITORS_OPINION — Наличие модифицированного мнения аудитора
- CASH_EQUIVALENTS — Денежные средства и их эквиваленты
- TOTAL_ASSETS — Итого активы
- PPE — Основные средства
- DEFERRED_TAX_ASSETS — Отложенные налоговые активы
- DEFERRED_TAX_LIABILITIES — Отложенные налоговые обязательства
- INTANGIBLE_ASSETS — Нематериальные активы
- TOTAL_EQUITY — Итого собственный капитал
- NET_INCOME — Чистая прибыль
- DIVIDENDS — Дивиденды
- INCOME_TAX — Расход по текущему налогу на прибыль
- TOTAL_ASSOCIATE_INVESTMENTS — Инвестиции в ассоциированные и совместные предприятия
- SHARE_CAPITAL — Уставной капитал
- SHARE_PREMIUM — Эмиссионный доход
- RETAINED_EARNINGS — Нераспределенная прибыль
- EPS — Прибыль на одну обыкновенную акцию
- DIVIDENDS_RECEIVED — Дивиденды полученные

## Рассчитываются во всех профилях (формула реестра над извлекаемыми)
- ROE — Рентабельность собственного капитала = формула зависит от профиля — см. aifa_state
- TOTAL_LIABILITIES — Итого обязательства = TOTAL_ASSETS - TOTAL_EQUITY
- TAX_EXPENDITURE — Общий расход по налогу = формула зависит от профиля — см. aifa_state
