# Коды ответов: что делать

Первая строка ответа любого инструмента — код. Ответ `aifa_wait` — итог того вызова, который ждал: читай его
по строке этого вызова. «Вне цикла» — ответ `aifa_goal` был не `НУЖЕН_ЦИКЛ`; «в цикле» — был, и `aifa_finish`
ещё не принят. Ответ без кода или обрыв связи считай `СБОЙ_СЛУЖБЫ`. Одна клетка «код × инструмент × условие» — одна строка.

| Код | Инструмент | Условие | Что делать |
|---|---|---|---|
| `ГОТОВО` | `aifa_goal` | всегда | результат получен, цикла нет: ответ пользователю по правилам 3–4 `SKILL.md`; `aifa_move` и `aifa_finish` не вызывай |
| `ГОТОВО` | `aifa_move`, `aifa_doc`, `aifa_state` | в цикле | не конец: иди дальше по плану, пользователю не отвечай, пока `aifa_finish` не принят (после `ЛИМИТ` — `aifa_finish` сразу, «Цикл» `SKILL.md`) |
| `ГОТОВО` | `aifa_doc`, `aifa_state` | вне цикла | чтение после `aifa_goal`: продолжай ответ по правилу 4 `SKILL.md` |
| `ЖДИ` | `aifa_goal`, `aifa_move`, `aifa_finish` | всегда | задание идёт фоном: `aifa_wait(job_id=<id>, wait_sec=240)` |
| `ЖДИ` | `aifa_wait` | всегда | снова `aifa_wait` с тем же `job_id` |
| `УТОЧНИ` | `aifa_goal` | всегда | вопрос пользователю: правило 3 `SKILL.md` |
| `НУЖЕН_ЦИКЛ` | `aifa_goal` | всегда | цикл открыт: «Цикл» `SKILL.md` |
| `ЛИМИТ` | `aifa_move`, `aifa_wait` | в цикле | ходов больше нет: `aifa_finish` сразу, «Цикл» `SKILL.md` |
| `ПРИНЯТО` | `aifa_finish` | всегда | цикл закрыт: ответ пользователю своими словами (раздел «Завершение»); если сказано «итог не принят» — по сводке из ответа |
| `СБОЙ_СЛУЖБЫ` | `aifa_goal` | всегда | правило 3 `SKILL.md` |
| `СБОЙ_СЛУЖБЫ` | `aifa_move`, `aifa_doc`, `aifa_state` | вне цикла | повтори тот же вызов один раз; не помогло — скажи пользователю, что расчёт сейчас недоступен |
| `СБОЙ_СЛУЖБЫ` | `aifa_move`, `aifa_doc`, `aifa_state` | в цикле | повтори тот же вызов один раз; не помогло — закрой цикл `aifa_finish`: `finalize` по имеющимся артефактам (чего нет — скажи), `give_up`, если артефактов нет, и скажи пользователю, что расчёт сейчас недоступен |
| `СБОЙ_СЛУЖБЫ` | `aifa_wait` | всегда | повтори `aifa_wait` один раз; снова сбой — задание сорвалось: повтори исходный вызов один раз; не помогло — по строке исходного вызова |
| `СБОЙ_СЛУЖБЫ` | `aifa_finish` | всегда | повтори один раз; не помогло — скажи пользователю, что расчёт сейчас недоступен, и что успело найтись (закрыть цикл нечем) |
| `ОТКАЗ` `нет_документа` | `aifa_goal` | всегда | правило 3 `SKILL.md` |
| `ОТКАЗ` `нет_документа` | `aifa_doc` | документа нет | в тексте «такого документа в этом ходе нет»: возьми `doc_id` из списка (`aifa_doc` без аргументов) |
| `ОТКАЗ` `нет_документа` | `aifa_doc` | текст не готов | в тексте «текст ещё не готов или не распознан»: скажи пользователю подождать или загрузить отчёт заново; чисел не называй |
| `ОТКАЗ` `неверные_аргументы` | `aifa_goal` | всегда | правило 3 `SKILL.md` («другой `ОТКАЗ`») |
| `ОТКАЗ` `неверные_аргументы` | `aifa_move`, `aifa_finish` | в цикле | вызов не принят и тратит ход цикла: исправь по тексту причины, тот же не повторяй |
| `ОТКАЗ` `неверные_аргументы` | `aifa_doc`, `aifa_state` | всегда | чтение не удалось, ход не потрачен: исправь аргументы (`pages` — «3-5», id артефактов — из таблицы, не больше 20) |
| `ОТКАЗ` `неверные_аргументы` | `aifa_wait` | свои аргументы | причина называет `job_id` или `wait_sec`: задание живо, исправь их (`job_id` — из «ЖДИ job=», `wait_sec` — от 10 до 240) |
| `ОТКАЗ` `неверные_аргументы` | `aifa_wait` | итог ждавшего вызова | причина про другое — это отказ `aifa_move` или `aifa_finish`, шедшего дольше 240 с: читай по строке того вызова; `aifa_wait` не повторяй, он отдаст то же |
| `ОТКАЗ` `задание_не_найдено` | `aifa_wait` | всегда | такого задания в ходе нет (потеряно при перезапуске службы): повтори исходный вызов один раз |
| `ОТКАЗ` `нет_цикла` | `aifa_move`, `aifa_finish` | всегда | цикл не открыт: отвечай пользователю по правилу 3 `SKILL.md` |
| `ОТКАЗ` `нет_цикла` | `aifa_doc`, `aifa_state` | всегда | чтение до `aifa_goal` в этом ходе: сначала `aifa_goal`; если он уже ответил не `НУЖЕН_ЦИКЛ`, `aifa_state` без аргументов недоступен — читай по `artifact_ids` |
| `ОТКАЗ` `цикл_закрыт` | `aifa_move`, `aifa_finish` | всегда | `aifa_finish` уже принят: ответ пользователю |
| `ОТКАЗ` `повтор_тупика` | `aifa_move` | в цикле | то же действие уже ничего не дало: смени путь (`moves.md`, «Итог прошлого хода») |
| `ОТКАЗ` `нет_входов` | `aifa_move` | в цикле | у атома с кодом входов ещё нет в артефактах: получи входы ходом, атом опиши следующим |
| `ОТКАЗ` `лимит_атомов` | `aifa_move` | в цикле | предел новых атомов: обойдись каталогом или `aifa_finish` |
| `ОТКАЗ` `не_dyn_тип`, `нет_единицы` | `aifa_move` | в цикле | контракт нового атома отклонён: исправь `output_type` / `x-unit` (`new-atom.md`) |
| `ОТКАЗ` `файл_не_собран` | `aifa_finish` | до ЛИМИТ | обещанного файла нет: собери его ходом из `files` и завершай снова (после `ЛИМИТ` служба принимает последнее слово и без файла — отказа не будет) |
| `ОТКАЗ` `чужой_ход` | `aifa_goal`, `aifa_wait`, `aifa_move`, `aifa_finish`, `aifa_doc`, `aifa_state` | всегда | ход уже закончен или остановлен, либо служба не признала его своим: не повторяй, скажи пользователю, что расчёт недоступен |
