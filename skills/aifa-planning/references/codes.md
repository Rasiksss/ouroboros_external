# Коды ответов: что делать

Первая строка ответа любого инструмента — код. Ответ `aifa_wait` — итог того вызова, который ждал: читай его
по строке этого вызова. «Вне цикла» — ответ `aifa_goal` был не `НУЖЕН_ЦИКЛ`; «в цикле» — был, и `aifa_finish`
ещё не принят.

| Код | Инструмент и условие | Что делать |
|---|---|---|
| `ГОТОВО` | `aifa_goal`: результат получен, цикла нет | ответ пользователю по правилу 4 `SKILL.md`; `aifa_move` и `aifa_finish` не вызывай |
| `ГОТОВО` | `aifa_move`, `aifa_doc`, `aifa_state` в цикле | не конец: иди по плану дальше; пользователю не отвечай, пока цикл не закрыт `aifa_finish` |
| `ГОТОВО` | `aifa_state(artifact_ids)` вне цикла | содержимое артефактов: продолжай ответ по правилу 4 `SKILL.md` |
| `ЖДИ` | `aifa_goal`, `aifa_move`, `aifa_finish` | задание идёт фоном: `aifa_wait(job_id=<id>, wait_sec=240)` |
| `ЖДИ` | `aifa_wait` | снова `aifa_wait` с тем же `job_id` |
| `УТОЧНИ` | `aifa_goal` | вопрос пользователю по правилу 3 `SKILL.md` |
| `НУЖЕН_ЦИКЛ` | `aifa_goal` | цикл открыт: раздел «Цикл» `SKILL.md` |
| `ЛИМИТ` | `aifa_move`, `aifa_wait` по ходу | ходов больше нет: `aifa_finish` сразу — как сказано в «Цикле» `SKILL.md` |
| `ПРИНЯТО` | `aifa_finish` | цикл закрыт: ответ пользователю своими словами (раздел «Завершение»); если сказано «итог не принят» — по сводке из ответа |
| `СБОЙ_СЛУЖБЫ` | `aifa_goal`, `aifa_move`, `aifa_doc`, `aifa_state` | повтори тот же вызов один раз; не помогло — вне цикла скажи пользователю, что расчёт сейчас недоступен; в цикле закрой его `aifa_finish` (`give_up`) и скажи это |
| `СБОЙ_СЛУЖБЫ` | `aifa_wait` | повтори `aifa_wait` один раз (задание может быть живо: исходный вызов не повторяй, иначе получишь второй такой же ход); не помогло — как выше |
| `СБОЙ_СЛУЖБЫ` | `aifa_finish` | повтори один раз; не помогло — скажи пользователю, что расчёт сейчас недоступен, и что успело найтись |
| `ОТКАЗ` `нет_документа` | `aifa_goal` | текст отчёта ещё не готов или не распознан: скажи пользователю подождать или загрузить отчёт заново; чисел не называй |
| `ОТКАЗ` `нет_документа` | `aifa_doc` | в тексте «такого документа в этом ходе нет» — возьми `doc_id` из списка (`aifa_doc` без аргументов); «текст ещё не готов или не распознан» — скажи пользователю подождать или загрузить отчёт заново |
| `ОТКАЗ` `неверные_аргументы` | `aifa_goal` | расчёт не выполнен: объясни это пользователю своими словами; чисел не называй |
| `ОТКАЗ` `неверные_аргументы` | `aifa_move`, `aifa_finish` | вызов не принят и тратит ход цикла: исправь по тексту причины, тот же не повторяй |
| `ОТКАЗ` `неверные_аргументы` | `aifa_doc`, `aifa_state` | чтение не удалось, ход не потрачен: исправь аргументы (`pages` — «3-5», id артефактов — из таблицы, не больше 20) |
| `ОТКАЗ` `неверные_аргументы` | `aifa_wait` | задание живо: исправь аргументы (`job_id` — из «ЖДИ job=», `wait_sec` — от 10 до 240) |
| `ОТКАЗ` `задание_не_найдено` | `aifa_wait` | такого задания в ходе нет (потеряно при перезапуске службы): повтори исходный вызов один раз |
| `ОТКАЗ` `нет_цикла` | `aifa_move`, `aifa_finish` | цикл не открыт: отвечай пользователю по правилу 3 `SKILL.md` |
| `ОТКАЗ` `нет_цикла` | `aifa_doc`, `aifa_state` | чтение до `aifa_goal` в этом ходе (или `aifa_state` без аргументов вне цикла): сначала `aifa_goal`; вне цикла артефакты читай по `artifact_ids` |
| `ОТКАЗ` `цикл_закрыт` | `aifa_move`, `aifa_finish` | `aifa_finish` уже принят: ответ пользователю |
| `ОТКАЗ` `повтор_тупика` | `aifa_move` | то же действие уже ничего не дало: смени путь (`moves.md`, «Итог прошлого хода») |
| `ОТКАЗ` `нет_входов` | `aifa_move` | у атома с кодом входов ещё нет в артефактах: получи входы ходом, атом опиши следующим |
| `ОТКАЗ` `лимит_атомов` | `aifa_move` | предел новых атомов: обойдись каталогом или `aifa_finish` |
| `ОТКАЗ` `не_dyn_тип`, `нет_единицы` | `aifa_move` | контракт нового атома отклонён: исправь `output_type` / `x-unit` (`new-atom.md`) |
| `ОТКАЗ` `файл_не_собран` | `aifa_finish` до `ЛИМИТ` | обещанного файла нет: собери его ходом из `files` и завершай снова (после `ЛИМИТ` служба принимает последнее слово и без файла — отказа не будет) |
| `ОТКАЗ` `чужой_ход` | `aifa_goal`, `aifa_wait`, `aifa_move`, `aifa_finish`, `aifa_doc`, `aifa_state` | ход уже закончен или остановлен, либо служба не признала его своим: не повторяй, скажи пользователю, что расчёт недоступен |
