# Внешние данные: поиск, затем загрузка

Того, чего нет в отчёте (ставки, курсы, цены, новости, события), в отчёте не найти: это внешние данные. Показатель отчётности компании, не найденный в отчёте, внешними данными не
является: искать его в интернете можно только с разрешения пользователя (`references/artifacts.md`).

- Ищи атомом каталога `web.search`: `concept` шага — текст запроса, как в поисковой строке;
  `extra.topic` — `news` для событий и решений с датой, `general` для справочных страниц и рядов
  данных. Несколько тем — несколько шагов одного хода, по запросу на тему:
  `{"atom": "web.search", "concept": "ключевая ставка Банка России 2026", "extra": {"topic": "news"}}`.
- Сценарием внешние данные не получить: сценарии работают только с отчётом.
- Перед расчётом проверь в первичном источнике определение ряда, единицы и период: полный год и
  часть года несопоставимы без отдельного объяснения. Прогноз не выдавай за фактическое значение;
  незавершённый год не имеет фактического среднегодового значения. Фрагмент поиска без этих
  сведений — повод загрузить источник, а не принять число. Если подтверждения нет, обозначь пропуск.
  Для каждого значения сохрани URL, дату публикации (если указана), дату обращения и охваченный
  период. При расчёте средней ставки по изменениям учитывай число календарных дней действия
  каждой ставки, а не среднее списка решений; метод и исходные интервалы сохрани.
- Находки появятся в таблице артефактов: заголовок, адрес, дата, начало фрагмента. Фрагментов
  хватает — отвечай по ним. Нужна страница целиком — атом-загрузка (`references/new-atom.md`): её
  `url` бери из находок, буква в букву; адрес по памяти не пиши.
- В итоге хода «поиск в интернете выключен пользователем» — не ищи обход ни поиском, ни загрузкой,
  ни другим атомом. Следующим ходом ответь и прямо скажи, что поиск выключен пользователем и где он
  включается: `aifa_finish(finalize)` — если в таблице артефактов уже есть данные отчёта для ответа
  (их id — в `evidence_ids`); артефактов нет — `aifa_finish(give_up)` с тем же объяснением в ответе.
- Как назвать внешние данные в ответе — раздел «Завершение» в `SKILL.md`.

Для рыночного дайджеста используй готовый `market_digest` в режиме `market` (см. `scenarios.md`); отдельные поиск и атомы-загрузки ему не нужны. Сетевой запрет хода распространяется на новости и макро.
