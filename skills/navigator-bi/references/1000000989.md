# Финансы Группы.PL по блокам — model reference

Group P&L and efficiency ratios cut by business blocks. Exact model, column, and indicator names must still be verified through `navigator_bi_search` `mode="schema"` before `query`; treat this file as domain knowledge, not as the wire catalog.

## Metrics

- P&L indicators follow the semantics of «Финансы Группы.PL» (flows, млрд руб, sum), cut by block; verify the exact indicator list via schema.
- Ratios specific to this model:

| Canonical indicator | Unit | Aggregation | Role | Synonyms / notes |
|---|---:|---|---|---|
| CIR | % | avg | ratio | Cost-to-Income Ratio; «эффективность», «расходы к доходам»; do not sum |
| COR | % | avg | ratio | Cost of Risk; do not sum |
| NIM | % | avg | ratio | Net Interest Margin; «маржа»; do not sum |

## Value semantics

- Value type: **Fact** for closed months, **Plan** for target values, **Forecast** for future months. Always state the value type in the answer; never present a forecast or plan as fact.
- Bases: «за месяц» = monthly flow; «с начала года» = YTD; «с начала квартала» = QTD. Use ready Navigator values for a base when available; do not recompute them from lower periods.
- Indicators in this model are **flows**: summable across periods, but only when the user explicitly asks and only via `calculator`.
- Do not add a total together with its components.
- CIR, COR, NIM are ratios: never sum them across periods or across blocks; use ready values, average only when explicitly requested.

## Ambiguity

- «маржа» usually means NIM.
- «эффективность» or «расходы к доходам» usually means CIR.
- «риск» or «потери» may mean COR or Расходы по созданию резервов; clarify.
- «доход» is ambiguous: ask whether the user means ЧПД, ЧКД, Операционный доход до резервов, or Прочие доходы.
- «доходы» often means Операционный доход до резервов, but clarify if the context is unclear.
- «прибыль» usually means Чистая прибыль / убыток. Do not confuse it with Прибыль до налога or Операционный доход.

## Answer discipline

- A point value is answered with: division, period, indicator, value, unit, value type.
- Name the block explicitly in the answer; when comparing, compare only sibling blocks of the same level.
- «Операции, не подлежащие аллокации» and «СОКИБ» — avoid using in interpretation unless the user asks for them explicitly.
- Expense variance: say «расходы ниже/выше плана» or «экономия/перерасход»; never describe a lower expense as "falling income".
- If nothing is returned for the requested parameters, say so; do not substitute numbers.
