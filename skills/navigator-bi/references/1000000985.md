# Финансы Группы. Кредиты и депозиты ЮЛ по сегментам — model reference

Corporate (юридические лица) credit AND funds balances of the Group, cut by client segment. Stocks, not flows. Dashboard label: «Кредиты». Exact model, column, and indicator names must still be verified through `navigator_bi_search` `mode="schema"` before `query`; treat this file as domain knowledge, not as the wire catalog.

**Naming trap:** despite the dashboard label «Кредиты», the model name states it also holds corporate funds — «депозиты ЮЛ» / «средства ЮЛ» belong here, not in the retail («Депозиты») model.

## Cut

- Segment dimension («по сегментам»): take segment values from schema/data. Some user aliases may look like block aliases (КИБ, ККСБ, ММБ) — verify against this model's schema before filtering; do not map blindly from the blocks table.

## Value semantics

- Value type: **Fact** for closed months, **Plan** for target values, **Forecast** for future months. Always state the value type in the answer; never present a forecast or plan as fact.
- Indicators in this model are **stocks**: balances as of a reporting date (aggregation `last`). Never sum them across months or dates.
- State balances «на дату», not «за период». Period dynamics = the difference between two dates, computed via `calculator`.

## Answer discipline

- Always name the date («на 01.12.2025»), not a period.
- If nothing is returned for the requested parameters, say so; do not substitute numbers.
