# Финансы ТБ/ГОСБ.PL с учетом корректировок к бизнес-плану — model reference

P&L by territorial banks (ТБ) and their branches (ГОСБ). Expected `sName` — confirm the exact name in the catalog. Exact model, column, and indicator names must still be verified through `navigator_bi_search` `mode="schema"` before `query`; treat this file as domain knowledge, not as the wire catalog.

## Model purpose

Expected role, derived from the model name — **not yet verified against schema**: fact and plan values, where the plan includes adjustments (корректировки) to the business plan. Expected use: fact values and план / отклонение от плана / выполнение плана questions; year-over-year dynamics («к прошлому году», «г/г», YoY) are expected in the paired model «Финансы ТБ/ГОСБ.PL YoY».

On first use of this pair in a conversation, call `mode="schema"` for both models and confirm which one holds the value types the user needs; if the split remains unclear, ask the user. Never present this expected split as a verified fact.

## Metrics

P&L indicators mirror the Group P&L set (Операционный доход до резервов, ЧПД, ЧКД, Операционные расходы, Резервы, Прибыль до налога, Налог, Чистая прибыль — млрд руб, sum, flows). Verify the exact indicator list for this model via schema; do not assume every Group line exists here.

## Value semantics

- Value type: **Fact** for closed months, **Plan** for target values, **Forecast** for future months. Always state the value type in the answer; never present a forecast or plan as fact.
- Bases: «за месяц» = monthly flow; «с начала года» = YTD; «с начала квартала» = QTD. Use ready Navigator values for a base when available; do not recompute them from lower periods.
- Indicators in this model are **flows**: summable across periods, but only when the user explicitly asks and only via `calculator`.
- Do not add a total together with its components.

## Ambiguity

- «доход» is ambiguous: ask whether the user means ЧПД, ЧКД, Операционный доход до резервов, or Прочие доходы.
- «доходы» often means Операционный доход до резервов, but clarify if the context is unclear.
- «прибыль» usually means Чистая прибыль / убыток. Do not confuse it with Прибыль до налога or Операционный доход.

## Answer discipline

- A point value is answered with: division, period, indicator, value, unit, value type.
- Expense variance: say «расходы ниже/выше плана» or «экономия/перерасход»; never describe a lower expense as "falling income".
- If nothing is returned for the requested parameters, say so; do not substitute numbers.

- Group-level figures → the corresponding «Финансы Группы.*» model.
