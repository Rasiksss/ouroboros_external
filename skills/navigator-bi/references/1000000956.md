# Финансы Группы.PL — model reference

Group-level P&L: monthly income statement lines for the bank and the Group. Exact model, column, and indicator names must still be verified through `navigator_bi_search` `mode="schema"` before `query`; treat this file as domain knowledge, not as the wire catalog.

## Metrics

| Canonical indicator | Unit | Aggregation | Role | Synonyms / notes |
|---|---:|---|---|---|
| Операционный доход до резервов | млрд руб | sum | total | операционный доход, опер. доход, operating income; income, not profit |
| Чистый процентный доход | млрд руб | sum | component | ЧПД, процентный доход, NII |
| Чистый комиссионный доход | млрд руб | sum | component | ЧКД, комиссии, NFI; here a component of operating income — the ФЛ/ЮЛ split lives in «Финансы Группы.ЧКД» |
| Операционные расходы | млрд руб | sum | component | OPEX, опер. расходы, расходы; negative value; lower absolute expense is better vs plan |
| Расходы по созданию резервов | млрд руб | sum | component | резервы, provisions; negative value; basis for COR |
| Прибыль до налога | млрд руб | sum | total | PBT, прибыль до налогообложения |
| Налог на прибыль | млрд руб | sum | component | налог, tax; negative value |
| Чистая прибыль / убыток | млрд руб | sum | total | прибыль, чистая прибыль, net income; after tax |

## Value semantics

- Value type: **Fact** for closed months, **Plan** for target values, **Forecast** for future months. Always state the value type in the answer; never present a forecast or plan as fact.
- Bases: «за месяц» = monthly flow; «с начала года» = YTD; «с начала квартала» = QTD. Use ready Navigator values for a base when available; do not recompute them from lower periods.
- Indicators in this model are **flows**: summable across periods, but only when the user explicitly asks and only via `calculator`.
- Do not add a total together with its components.

## Ambiguity

- «доход» is ambiguous: ask whether the user means ЧПД, ЧКД, Операционный доход до резервов, or Прочие доходы.
- «доходы» often means Операционный доход до резервов, but clarify if the context is unclear.
- «прибыль» usually means Чистая прибыль / убыток. Do not confuse it with Прибыль до налога or Операционный доход.

## Answer discipline

- A point value is answered with: division, period, indicator, value, unit, value type.
- Expense variance: say «расходы ниже/выше плана» or «экономия/перерасход»; never describe a lower expense as "falling income".
- If nothing is returned for the requested parameters, say so; do not substitute numbers.

## Related models

- ЧКД split by Физлица/Юрлица → «Финансы Группы.ЧКД».
- P&L cuts live in separate models: «Финансы Группы.PL по блокам», «…PL по продуктам», «…PL по ДЗО». When the user asks for a cut («в разрезе …»), pick the matching model; if the requested cut is ambiguous, ask.
- Balances: corporate → «Финансы Группы. Кредиты и депозиты ЮЛ по сегментам»; retail → «Финансы Группы. Кредиты и депозиты ФЛ по продуктам»; balance sheet → «Финансы Группы.Баланс».
