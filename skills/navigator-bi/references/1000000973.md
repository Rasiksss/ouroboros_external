# Финансы Группы.Баланс — model reference

Group balance sheet: assets, liabilities, and capital as of a reporting date. Stocks, not flows. Exact model, column, and indicator names must still be verified through `navigator_bi_search` `mode="schema"` before `query`; treat this file as domain knowledge, not as the wire catalog.
The indicator inventory of this model has not been curated yet: always take exact indicator names from `mode="schema"`, and prefer asking the user over assuming.

## Metrics

Balance-sheet lines (активы, пассивы, капитал, валюта баланса and their components) — resolve exact indicator names via schema; do not assume line names or hierarchy.

## Value semantics

- Value type: **Fact** for closed months, **Plan** for target values, **Forecast** for future months. Always state the value type in the answer; never present a forecast or plan as fact.
- Indicators in this model are **stocks**: balances as of a reporting date (aggregation `last`). Never sum them across months or dates.
- State balances «на дату», not «за период». Period dynamics = the difference between two dates, computed via `calculator`.
- Do not add a total (e.g. валюта баланса, итого активы) together with its components.

## Answer discipline

- Always name the date («на 01.12.2025»), not a period.
- If nothing is returned for the requested parameters, say so; do not substitute numbers.
