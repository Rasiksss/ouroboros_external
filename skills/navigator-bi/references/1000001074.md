## Value semantics

- Value type: **Fact** for closed months, **Plan** for target values, **Forecast** for future months. Always state the value type in the answer; never present a forecast or plan as fact.
- This model may mix ratios, flows, and stocks: check the unit and meaning of each indicator (via schema and row values) before aggregating anything.
- Ratios (%): never sum across periods or divisions; use ready values, average only when explicitly requested.
- Do not add a total together with its components.

## Answer discipline

- A point value is answered with: division, period, indicator, value, unit, value type.
- If nothing is returned for the requested parameters, say so; do not substitute numbers.
