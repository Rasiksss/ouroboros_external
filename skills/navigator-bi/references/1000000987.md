# Финансы Группы. Кредиты и депозиты ФЛ по продуктам — model reference

Retail (физические лица) credit AND funds balances of the Group, cut by product. Stocks, not flows. Dashboard label: «Депозиты». Exact model, column, and indicator names must still be verified through `navigator_bi_search` `mode="schema"` before `query`; treat this file as domain knowledge, not as the wire catalog.

**Naming trap:** despite the dashboard label «Депозиты», the model name states it also holds retail credits — «кредиты ФЛ» / «розничные кредиты» belong here, not in the corporate («Кредиты») model.

## Cut

- Product dimension («по продуктам»): take product values (e.g. mortgage/consumer/deposit products) from schema/data; do not invent product names.

## Value semantics

- Value type: **Fact** for closed months, **Plan** for target values, **Forecast** for future months. Always state the value type in the answer; never present a forecast or plan as fact.
- Indicators in this model are **stocks**: balances as of a reporting date (aggregation `last`). Never sum them across months or dates.
- State balances «на дату», not «за период». Period dynamics = the difference between two dates, computed via `calculator`.

## Answer discipline

- Always name the date («на 01.12.2025»), not a period.
- If nothing is returned for the requested parameters, say so; do not substitute numbers.
