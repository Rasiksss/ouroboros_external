# aifa-engine

Расширение с инструментами службы расчётов AIFA. Оно только передаёт вызов службе и возвращает её
ответ без изменений; все правила и числа — на стороне службы.

Когда и в каком порядке вызывать инструменты, написано в навыке `aifa-planning`; здесь — только то,
что нужно знать об устройстве:

- `aifa_open` — без аргументов: открывает цикл по документу хода и возвращает его состояние.
- `aifa_wait(job_id, wait_sec)` — ждёт фоновое задание из ответа `ЖДИ job=<id>`.
- `aifa_state`, `aifa_doc` — чтение: состояние цикла и артефакты Case; документы хода и их текст по страницам.
- `aifa_move`, `aifa_finish` — ход цикла и его завершение; работают после успешного `aifa_open`; ходы ведёт только корень.
- Первая строка ответа — код (`ГОТОВО`, `ЖДИ`, `ЛИМИТ`, `ПРИНЯТО`, `ОТКАЗ <код>`, `СБОЙ_СЛУЖБЫ`), дальше — текст.
