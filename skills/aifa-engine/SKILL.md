# aifa-engine

Расширение с инструментами службы расчётов AIFA. Оно только передаёт вызов службе и возвращает её
ответ без изменений; все правила и числа — на стороне службы.

Если реестр не помещается в `aifa_state`, читай `aifa_state(registry_offset=0)` и продолжай по
`next_offset` до null. Смещение — в символах полного реестра; режим не совмещается с артефактами.

**Термины.** План — набор ходов. Ход — набор шагов. Шаг — действие с конкретным результатом: вызов атома, часть цели
со сценарием службы, заказ подзадачи. Прогон — вся работа над сообщением пользователя.

Когда и в каком порядке вызывать инструменты, написано в навыке `aifa-planning`; здесь — только то,
что нужно знать об устройстве:

- `aifa_open` — без аргументов (или `mode="report"`) открывает цикл по документу;
  `mode="market"` открывает рыночный цикл без документа для `market_digest`. Режим открытого цикла не меняется.
- `aifa_wait(job_id, wait_sec)` — ждёт фоновое задание из ответа `ЖДИ job=<id>`.
- `aifa_state`, `aifa_doc` — чтение: состояние цикла и артефакты Case; документы хода и их текст по страницам.
- `aifa_atoms` — каталог атомов: `list` — карточки (версия, входы, выходы, форматы, ограничения), `get` — контракт и код
  одного атома; читают корень и подзадачи.
- `aifa_move`, `aifa_finish` — ход цикла и его завершение; работают после успешного `aifa_open`; ходы ведёт только корень.
- Первая строка ответа — код (`ГОТОВО`, `ЖДИ`, `ЛИМИТ`, `ПРИНЯТО`, `ОТКАЗ <код>`, `СБОЙ_СЛУЖБЫ`), дальше — текст.

Дайджест: `aifa_move(goals=[{"ref":"g1","scenario":"market_digest","parameters":{"since_hours":168}}], objective="Дайджест за неделю", reason="Запрос пользователя")`.
Период — целое число часов 6–336, по умолчанию 48. Жди `ЖДИ` через `aifa_wait`; читай сохранённый
`DigestOutput` через `aifa_state(artifact_ids=[id])`. Для длинного выпуска продолжай по
`artifact_offset=next_offset` до null. Полный порядок — в `aifa-planning`.
