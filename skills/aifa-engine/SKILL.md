# aifa-engine

Расширение с инструментами службы расчётов AIFA. Оно только передаёт вызов службе и возвращает её
ответ без изменений; все правила и числа — на стороне службы.

Когда и в каком порядке вызывать инструменты, написано в навыке `aifa-planning`; здесь — только то,
что нужно знать об устройстве:

- `aifa_goal` — без аргументов. Службе не нужна ваша формулировка цели: она берёт исходное
  сообщение пользователя сама.
- `aifa_wait(job_id, wait_sec)` — ждёт фоновое задание из ответа `ЖДИ job=<id>`.
- Первая строка ответа — код (`ГОТОВО`, `ЖДИ`, `УТОЧНИ`, `ОТКАЗ <код>`, `СБОЙ_СЛУЖБЫ`), дальше — текст.
