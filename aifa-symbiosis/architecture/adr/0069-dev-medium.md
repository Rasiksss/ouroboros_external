# ADR-0069. Dev: задачи используют medium вместо high

Статус: эксперимент отклонён; живая настройка заменена ADR-0071 (22.10.2026)
Уточняет: ADR-0067, ADR-0058 в части живого окружения

## Контекст
Файловый прогон DeepSeek-V4-Pro с `OUROBOROS_EFFORT_TASK=high` создал Excel примерно
через 40 минут. Только ответ планировщика занял 246 секунд и 12547 completion tokens.
Основные и вспомогательные задачи получают один заданный окружением уровень.

## Решение
Следующий сопоставимый UI-прогон провести с `OUROBOROS_EFFORT_TASK=medium`.
Модели, запрос, отчёт, критерии приёмки и бюджеты оставить прежними. До пересоздания
процесса сохранить серверный env. Окончательный выбор сделать после проверки файла
и повторного успешного прогона. Настройку отдельного пользователя не изменять.

## Следствия
Меньше времени на рассуждения; полнота и финансовая корректность проверяются отдельно.
Ускорение само по себе не считается успехом.

## Чем проверяется
В журнале новых задач `reasoning_effort=medium`; длительность и результат полного
UI-прогона, три листа, формулы, источники и явные ограничения данных в итоговом Excel.
