# ADR-0100. Dev: модели Cloud.ru, Chromium в engine, контактный User-Agent для SEC

Статус: принято (прямое поручение владельца, 28.10.2026)
Заменяет ADR-0097 в части провайдера: маршрут OpenRouter через Infproxy на dev больше не используется.

## Контекст

Ключ OpenRouter на dev исчерпал кредиты (HTTP 402 на классификации дайджеста). В выпуске недоступны
58 из 181 источников: 39 EDGAR отвечали 403 на общий User-Agent, 17 e-Disclosure требуют браузера,
которого нет в образе engine, ещё два — сертификат Росстата и защитная заглушка Forbes.

## Решение

- Только compose-проект `aifa-sym`. Служба и ouroboros ходят в Cloud.ru
  (`https://foundation-models.api.cloud.ru/v1`) напрямую: корень и служба — `deepseek-ai/DeepSeek-V4-Pro`,
  планировщик службы и автор атомов — `deepseek-ai/DeepSeek-V4.1-Flash` (`V4-Flash` недоступна проекту),
  автор плана — `zai-org/GLM-5.3@low`, классификатор дайджеста — `V4.1-Flash` (на пакете из 100 новостей
  `V4-Pro` не укладывалась в 360 с клиента). Ключ Cloud.ru — из сохранённой копии окружения; значения в git нет.
- `FINENGINE_FRED_API_KEY` и `FINENGINE_EIA_API_KEY` скопированы из окружения prod (чтение, prod не менялся).
- Образ engine дополнен Chromium (`/ms-playwright`) тонким слоем поверх прежней базы.
- Сбор дайджеста: EDGAR запрашивается с контактным User-Agent исходного коннектора и темпом ниже предела SEC;
  ленты — с браузерными заголовками исходного RSS-коннектора; адреса Росстата — с центрами Минцифры.
  Ключи провайдеров маскируются в журнале httpx.
- Откат: `bash ~/aifa-sym-switch-to-cloudru.sh rollback`; теги образов `before-*`; копия env в
  `~/aifa-sym-llm-before-cloudru-*`.

## Следствия

Остаётся один недоступный источник из 181 (`forbes_ru`) и блок Investing (403 Cloudflare): выпуск `partial`.
Cloud.ru медленнее на крупных запросах; срок клиента 360 с.
