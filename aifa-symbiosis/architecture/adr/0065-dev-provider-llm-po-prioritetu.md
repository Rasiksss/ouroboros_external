# ADR-0065. Dev: провайдер LLM выбирается по приоритету OpenRouter → Holy API → Cloud.ru

Статус: принято (владелец, 22.10.2026: «Приоритет такой OpenRouter, holyapi, cloud»; ключ OpenRouter исчерпан)
Уточняет: ADR-0056, ADR-0057, ADR-0058 (провайдер и модель живого dev); ADR-0055 (Holy API как канал). Модель не меняется.

## Контекст
- 22.10.2026 в 11:40 живой прогон оборвался: ключ OpenRouter через `infproxy` отвечает `403 Key limit exceeded
  (total limit)`, `$150.06 of $150.00 used; does not reset`. Нет запасной модели: ouroboros и служба ходят в одну точку.
- Holy API (ADR-0055) отвечает: `GET /models` — 200, короткие запросы к `glm-5.3`, `glm-5.2`, `deepseek-v4.1-flash` — `ок`;
  имя модели без префикса (`z-ai/glm-5.3` там не существует). Cloud.ru доступен через `infproxy` по запасному
  каналу (`INFPROXY_UPSTREAM_ALT`, модели `zai-org/GLM-5.2`, `deepseek-ai/DeepSeek-V4-Pro` и др.), GLM-5.3 в нём нет.

## Решение
1. Порядок выбора канала для dev: OpenRouter через `infproxy` → Holy API напрямую → Cloud.ru. Берётся первый,
   который отвечает коротким запросом к нужной модели; доступность проверяется перед переключением.
2. Модель остаётся GLM-5.3 на всех ролях (ADR-0058): при переходе на Holy меняется только канал и написание имени
   (`glm-5.3`, ouroboros — `cloudru::glm-5.3`). Уровень размышлений и пределы времени не меняются.
3. Переключение — только правкой серверных `ouroboros.env` и `engine.env` (`CLOUDRU_FOUNDATION_MODELS_*`,
   `OUROBOROS_MODEL*`, `FINENGINE_OPENROUTER_*`, `OPENROUTER_API_KEY`, `FINENGINE_*_MODEL`) с копией до правки и
   пересозданием `ouroboros` и `engine`; ключ берётся из сохранённой копии и не печатается. `infproxy` не меняется.
4. 22.10.2026 выбран Holy API: OpenRouter не отвечает, Holy — отвечает на нужной модели. Примеры в `aifa/deploy/dev/*.example`
   не меняются (они уже описывают Holy; F9 держит их).

## Следствия
- Прогоны на dev не зависят от лимита одного ключа; возврат на OpenRouter — тем же способом после пополнения ключа.
- Скорость и качество ответов Holy на `glm-5.3` не измерялись; сравнение — по первому прогону после выкатки.
- Копии до переключения: `~/aifa-sym-{ouroboros,engine}.env.before-holy2-20261022-121444` (на сервере).

## Чем проверяется
Короткие запросы к выбранному каналу перед и после переключения (дымовые 2 и 9 `smoke/run.sh`); F9 проверяет примеры, не живой файл.
