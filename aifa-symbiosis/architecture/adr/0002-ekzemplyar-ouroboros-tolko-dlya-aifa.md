# ADR-0002. Экземпляр ouroboros только для AIFA, агент `main`, один процесс

Статус: принято (владелец, 13–14.10.2026; решение №1 и «режим ouroboros»)

## Контекст
Ouroboros умеет много владельцев и агентов (`OwnerScope`), режимы «один процесс» (`server.py`) и
«пять процессов» (`multiuser_config/`). AIFA нужна пара пользователей.

## Решение
Экземпляр ouroboros обслуживает только AIFA. Агент AIFA — агент по умолчанию `main`, которого
реестр создаёт сам. Режим — один процесс `server.py` с `OUROBOROS_MULTIUSER=true` (личность из
доверенных заголовков, ADR-0014).

## Следствия
- Служба движка не передаёт `X-Ouroboros-Agent-Id`: пустой заголовок разрешается в агента по
  умолчанию (`transport/browser/identity.py`, `_resolve_scoped_agent`). Контрактный тест C2.1
  проверяет, что это `main`.
- Набор навыков и инструментов задаётся окружением сразу для всех владельцев (ADR-0027), а не
  настройкой агента каждого владельца.

## Чем проверяется
C2.1, F9.
