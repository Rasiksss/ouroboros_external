# ADR-0070. Проверка определения показателей и внешних рядов

Статус: принято для проверки на dev (22.10.2026)

## Контекст
Прогон c9a290dc создал три листа и формулы, но заменил отсутствующие депозиты
всеми краткосрочными финансовыми вложениями. Прогноз ставки за 2025 год выдан
за факт, для 2026 использован иной период; вместо ссылок на страницы — текст.
Формальная успешность исполнения не подтвердила выполнение запроса.

## Решение
Уточнить навык корня: отсутствие операнда не разрешает менять определение
показателя без подтверждённой эквивалентности. Проверять тип внешнего значения,
период, первичный источник и дату обращения. При приёмке файла проверять
источники операндов, ссылки и выводы, а не только структуру.
Решения остаются у модели; финансовые эвристики в Python не вводятся.

## Следствия и проверка
Допустим честный частичный результат при отсутствии данных. Текстовые
регрессии защищают инструкции; качество подтверждается отдельным UI-прогоном
и чтением фактически скачанного Excel. Сами текстовые тесты качества не доказывают.
