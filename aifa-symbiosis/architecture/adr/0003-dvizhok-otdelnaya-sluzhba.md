# ADR-0003. Движок — отдельная служба

Статус: принято (владелец, решение №2)

## Решение
finengine работает отдельной службой (свой процесс, образ, окружение Python): вход пользователей,
ручки фронтенда, журнал хода и события экрана, разбор запроса, граф, атомы, `Case`, проверки,
реестр показателей. Без OpenClaw и без своего ведущего цикла (ADR-0023).

## Следствия
Граница служба ↔ ouroboros — только сеть: WebSocket и HTTP браузерного транспорта в одну сторону,
внутренний HTTP API службы в другую. Импортов между ними нет (F2).

## Чем проверяется
F2, C2, C3.
