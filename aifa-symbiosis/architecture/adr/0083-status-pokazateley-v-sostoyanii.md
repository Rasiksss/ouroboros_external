# ADR-0083. Статус показателей в состоянии цикла; переделка шага опирается на состояние

Статус: принято (владелец, 26.10.2026) для проверки на dev; дополняет ADR-0082

## Контекст
Прогон ЛУКОЙЛ в UI (чат a522144a, 26.10): шаг расчёта чистого долга упал, корень сам выводил из итога хода,
что не хватило BANK_DEPOSITS, и выбирал способ новой попытки по догадке. В состоянии цикла (`aifa_state`)
этого не записано: есть реестр, таблица артефактов и текст итога хода, но нет прямого ответа, найден ли
показатель и посчитан ли он.

## Решение
Служба (`aifa/finengine`) и тексты навыков; ядро ouroboros и `task_plan` не затрагиваются.
- Новый раздел «Статус показателей» в `state_sections` (после «Реестра показателей»; его читают и ouroboros, и
  служба): по каждому показателю частей цели и, рекурсивно, компонентам его формулы реестра — строка
  `извлечение — …; расчёт — …`. Слова строгие: «найден (периоды)», «НЕ НАЙДЕН» (пробовали, значения нет),
  «рассчитан (периоды)», «НЕ РАССЧИТАН: нет значений: …» (названо отсутствующее значение, не промежуточный
  итог), «не пробовали», «не извлекается», «формулы реестра нет», «вне реестра».
- Значения берутся из таблицы артефактов (`ExtractedMetric`, `CalculatedMetric`), состав формул — из реестра;
  «пробовали» пишет `LoopSession` и при исполнении частей цели по ссылке (расчёт отмечает и компоненты), и при
  исполнении шагов атомов: `locate`/`read.value` — попытка извлечь, `calc.formula` — попытка посчитать; записывается
  и когда значения нет. В разделе — показатели частей цели и всё, что пробовали шагами. Модуль
  `skills/spec/metric_status.py`.
- Отказ части цели для агента (`dynamic_run.py`) больше не велит «заказать пересмотр плана у планировщика», а
  отсылает к разделу «Статус показателей» и к новой попытке того же шага (меняет ADR-0080).
- `plans.md` — для любого упавшего шага: способ новой попытки выбирают по записям (`aifa_state`: итог хода, статус
  части цели, статус показателей, таблица, атомы «НЕ ЗАПУЩЕН»; итог исполнителя `get_task_result`), а не по
  догадке. `artifacts.md` — для показателей: «НЕ НАЙДЕН» и расчёт не пробовали → расчёт реестра; «НЕ РАССЧИТАН: нет
  значений» → поиск недостающих значений в интернете за тот же период и расчёт по найденному; не дал → `partial`.

Ограничение: показатель, по которому есть артефакты, но нет ни части цели, ни попытки (например, из детерминированного
пути до цикла), в раздел не попадает, пока его не назовёт часть цели или шаг; раздел не растёт до всего реестра.
Ничего, что корень посчитал сам вне службы, состояние не видит — это запрещено правилом навыка.

## Проверка
`tests/dynamic_run/test_metric_status_state.py` (20: слова статуса, компоненты, рекурсия, «пробовали» после
отказа части и после шагов атомов, раздел в состоянии); `tests/loop_tools/test_agent_goals.py`; перечень разделов в
`test_web_search_review.py`; тексты навыков — `test_calculated_values_and_final_text.py`. Живой прогон: строка
NET_DEBT в состоянии называет BANK_DEPOSITS, корень идёт по таблице способов без догадок.
