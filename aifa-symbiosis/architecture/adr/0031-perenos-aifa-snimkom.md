# ADR-0031. Код AIFA переносится снимком без истории git

Статус: принято (владелец, 14.10.2026; вопрос О1)

## Контекст
Код AIFA переносится в `aifa/` (ADR-0019) из `Baltazar2795/AIFA-CLAW`, ветка
`feature/Claw-v2-1.0` @ `f4a12fc6` (09.10.2026). Можно перенести только файлы или файлы вместе с
историей коммитов (`git filter-repo`). Ouroboros перенесён снимком (ADR-0030).

## Решение
Перенос — снимком: файлы нужных путей берутся из коммита `f4a12fc6` (`git archive`, не рабочее
дерево) и коммитятся одним структурным коммитом. Сообщение называет исходник: репозиторий, ветку,
коммит, дату, список путей. История AIFA остаётся в исходном репозитории.

## Следствия
- `git blame`/`git log` по файлам AIFA в новом репозитории доходят только до коммита переноса;
  дальше — исходный репозиторий, где работают и хэши из `34-status.md`.
- Старые секреты из истории AIFA не попадают в новый репозиторий, который пушится на GitHub.
- Обе части симбиоза начинаются со снимка — проверки и правила одинаковые.

## Чем проверяется
Шаг 01: сравнение `aifa/` с `git archive f4a12fc6` (только названные правки путей); сообщение
коммита переноса.
