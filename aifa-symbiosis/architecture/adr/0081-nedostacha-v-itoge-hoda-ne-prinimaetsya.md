# ADR-0081. Недостача в итоге хода не принимается шагом

Статус: принято (владелец, 24.10.2026) для проверки на dev

## Контекст
Прогон Excel по ЛУКОЙЛу 24.10: BANK_DEPOSITS в итоге хода вернулся «не найден», корень принял шаг
`accept_step`, пометил в файле «в отчёте отсутствуют» и посчитал чистый долг без депозитов. Пересмотра
плана не было, ADR-0080 в деле не сработал. Причины в текстах: приёмка («всё, что вернул движок, —
истина») принимала шаг с недостачей внутри хода; `finalize` разрешал «по имеющимся» без различия, чего не
хватает; недостача включалась только после провала шага. Название компании корень взял из имени файла.

## Решение
Только тексты навыков, ядро и служба не затрагиваются.
- `plans.md`: «не найден» в итоге хода — недостача, даже если остальные части получены, и у компонента
  формулы запрошенного расчёта; такой шаг не принимается, расчёт без показателя не выдаётся, пометка «в
  отчёте отсутствует» недостачу не закрывает; `partial` — только после пересмотра, с перечнем недостающего.
- `aifa-planning` 2.8.0: «`finalize` по имеющимся» не распространяется на показатель запроса до
  пересмотра плана; компанию называть как в `aifa_state`, а не по имени файла.
- `aifa-plan-author` 1.7.0: найденное снаружи сохраняет дату обращения и тот же период, что у отчёта;
  расчёт без недостающего компонента не планируется.

## Проверка
Четыре текстовых теста (`test_calculated_values_and_final_text.py`); живой прогон: ведёт ли «не найден»
по BANK_DEPOSITS к новой ревизии плана и верно ли названа компания.
