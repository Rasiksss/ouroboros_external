# ADR-0073. Предложение плана в Markdown-ограждении принимается

Статус: принято для проверки на dev (23.10.2026); правка ядра разрешена владельцем

## Контекст
В прогонах 61b91465 и 3891d3f7 автор плана несколько раз вернул корректный JSON в ограждении
```` ```json ```` (и с текстом перед ним). `task_plan` отклонял его как «Invalid JSON», корень заказывал
новый план: на втором прогоне три отклонения из четырёх ушли на ~15 минут. Навык автора плана уже
требует «без Markdown-ограждения»; модель требование не выполняет.

## Решение
`task_plan(action="accept")` разбирает итог подзадачи через `_proposal_json`: берётся последний
блок в ограждении, начинающийся с `{`; сообщение без такого блока остаётся как есть, и ошибка
валидации называет настоящий текст. Схема, права записи, цепочка подзадачи и хеш результата
(`child.result`) не меняются: проверяется тот же полный результат, меняется только извлечение объекта.
Поиск «первая `{` — последняя `}`» не вводится: он принял бы фрагменты из рассуждений.

Файл `ouroboros/tools/service/task_planning.py` уже разрешён к правке ADR-0062 (F1); эта запись
дополняет его.

## Проверка
Три теста принимают план в ограждении, с текстом перед ограждением и в ограждении без языка; два
теста сохраняют отказ для текста без JSON и для блока, не являющегося объектом
(`tests/ouroboros/tools/test_task_planning.py`).
