# ADR-0004. Ouroboros принимает сообщение первым; конвейер — его инструмент

Статус: принято (владелец, решение №3); гарантия заменена ADR-0040 (MVP); «цель только из исходного сообщения» в силе (ADR-0042); следствие о цели из сообщения заменено ADR-0060

## Решение
Сообщение пользователя служба передаёт в ouroboros без изменений. Ouroboros по навыку
`aifa-planning` первым делом вызывает «выполнить цель» (`aifa_goal`). Гарантию «числа только из
доказательной базы» держат три меры:
1. ouroboros не видит текста документа (граница — ADR-0025);
2. инструменты цикла отказывают, пока стандартный путь не попытался и не открыл цикл;
3. «завершить» не принимает ссылок на несуществующее и опровергнутое.

## Следствия
«Выполнить цель» не принимает текста цели от модели: служба берёт исходное сообщение своего
прогона. Модель не может переформулировать цель.

## Чем проверяется
C3 (отказы без стандартного пути, `finalize` по несуществующему), F3.
