# ADR-0096. Полный реестр и периоды отчёта доступны планировщику

Статус: принято (поручение владельца исправить входной контекст, 27.10.2026)

## Контекст

`ouro_view._state` отрезает хвост реестра вместе с рассчитываемыми показателями, чтобы уложить
состояние и дублирующий каталог в result_limit. Продолжения нет. Профиль не показывает компанию
и периоды. Пример навыка разделяет авторов статистик и Excel вопреки ADR-0087.

## Решение

- Сначала сокращается дублирующий каталог. Если реестр не помещается, вместо обрезанного текста
  состояние возвращает указание читать `aifa_state(registry_offset=0)`.
- `registry_offset` — неотрицательное смещение в символах полного реестра замороженного паспорта.
  Ответ ограничен result_limit, возвращает next_offset; null означает конец. Все страницы вместе
  дают исходный реестр без потери названий, кодов и формул. С артефактами режим не смешивается.
- Компания берётся из RunPassport.entity, периоды определяются один раз по шапке первой таблицы с периодами
  существующим нормализатором; без таблиц используется `_select_run_periods` только на обложке.
  Полный текст давал ложные даты из примечаний (2013 и 9M 2025 в живом отчёте). Это контекст заголовков, а не
  гарантия наличия значения каждого показателя или полный перечень всех примечаний. Извлечение
  не ограничивается этими периодами. Пустой результат явно обозначается неизвестным.
- Планировщик дочитывает продолжения реестра, не считает отсутствием показателя неполный ответ.
  Пример объединяет статистики, выводы и Excel в одного автора после получения всех входов.

## Проверка

Регрессии состояния и HTTP-инструмента проверяют ограниченный размер, восстановление полного
реестра, формулы EBITDA/NET_DEBT, отказ неверным/смешанным аргументам, компанию и периоды без
добавления предыдущего года по догадке. Тест текста навыка проверяет пример с одним автором.
Повтор сравнения моделей выполняется на том же запросе UI и исправленном входном контексте.
