# ADR-0018. Только dev; prod не трогать; нагрузка — пара пользователей

Статус: принято (владелец, решения №23–24, №26)

## Решение
Всё разворачивается только на dev. Чистить диск dev разрешено. prod (`finengine-prod-*`,
`openclaw-prod-gw`, `workstation-svc-prod`, `finengine-caddy-1`, `infproxy`) не трогать никак.
Масштабирование отложено.

## Чем проверяется
F9 (имя compose-проекта и сервисов без `prod`, нет ссылок на контейнеры prod).
