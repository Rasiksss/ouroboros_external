# ADR-0061. План предлагает подзадача, принимает и проверяет корневой ouroboros

Статус: принято (владелец, 21.10.2026: обсуждение трёх контрактов и «Хорошо, давай реализовывать»)
Уточняет: ADR-0041, ADR-0060. Исключение из заморозки ядра — только перечисленные файлы F1.

## Контекст
Прогон d2a3bf71-961a-4c44-8fbd-bf4fe7c71701 подменил двухлистный Excel однолистным экспортом,
не создал презентацию и не вызвал автора. Владелец исключил службу из приёмки пользовательской
задачи и поручил вынести планирование в подзадачу оркестратора.

## Решение
1. Корень открывает данные AIFA и поручает `distribution:aifa-plan-author` только составление плана.
   Подзадача возвращает полный JSON финальным результатом задачи, без `aifa_report(done)`.
   Требования с цитатами запроса, допущения, вопросы, шаги, зависимости и критерии разделены.
2. Универсальный инструмент ouroboros `task_plan` читает схему и план, принимает предложение из
   результата завершённой прямой подзадачи, записывает исполнение шагов и решения корня по критериям.
   Только корень меняет план. Технические проверки формы и ссылок не оценивают качество ответа.
3. Одно зашифрованное состояние плана хранится в runtime PostgreSQL, в `task_plans`, с областью
   владельца/агента/поверхности/чата/корня. Версия состояния защищает от устаревших записей;
   ревизии предложений и история решений сохраняются. Проверки результата содержат ссылки на
   конкретную версию наблюдения. Принимает смысл результата корень, не служба и не код инструмента.
4. `accepted` отличается от `awaiting_review`. Полное завершение требует принятых шагов;
   частичное сохраняет незавершённые шаги и причину. Успех runtime сам по себе не означает полноту.
5. Навык корня использует принятый план как единственный пользовательский план. `aifa_move` — задание
   исполнителю; существующие plan/files службы не используются корнем как второй план. Семантический
   файловый гейт службы отключается в агентском пути; техническая проверка файлов остаётся.
6. Допуск нового навыка и инструмента — примеры dev/contract. Выкатка не входит в разрешение на код.
   Каталог атомов, новая система исходов и восстановление графов, изменения версий методики и состава
   анализа не входят в эту работу.

## Проверка
Тесты настоящих инструментов и PostgreSQL: завершённая подзадача → принятие → шаг → проверка → итог;
отказы чужой области, подзадаче-писателю, устаревшей версии, неполной проверке и изменённым зависимостям.
Контрактный тест навыков проверяет делегирование и отсутствие короткой сдачи плана.
