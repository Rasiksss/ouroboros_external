# ADR-0068. Типизированный поток событий запрещает преобразование прокси

Статус: принято (22.10.2026, поручение владельца стабилизировать dev UI)
Уточняет: ADR-0015, ADR-0021

## Контекст
Через фронтенд Next.js запрос `/chat/runs/<id>/events` с `Accept-Encoding: gzip`
получает `Content-Encoding: gzip`, но чтение первой распакованной строки не завершается
за 8 секунд. Тот же журнал с `Accept-Encoding: identity` отдаёт первую строку за 0,007 с.
В UI нет прогресса даже при работающем агенте; перезагрузка этого не устраняет.

## Решение
В общем ответе типизированного SSE добавить `no-transform` к `Cache-Control: no-cache`.
Прокси передаёт кадры без компрессии и её буфера. Формат кадров, авторизация,
`Last-Event-ID`, порядок журнала и структура экрана не меняются.

## Следствия
Небольшие кадры достигают браузера сразу. Остальные HTTP-ответы сохраняют сжатие.

## Чем проверяется
`test_events_end_of_a_failed_turn.py`: настоящий endpoint сохраняет конечный кадр
и объявляет `no-transform`. На dev: запрос через фронтенд с gzip не сжимается,
первая строка приходит сразу; UI показывает инструменты до окончания хода.
