# ADR-0063. UI сохраняет подписку на долгую подзадачу

Статус: принято (22.10.2026, поручение владельца исправить найденное прогоном и удвоить лимиты).
Уточняет ADR-0062 для фронтенда.

## Контекст

В повторном прогоне356e44aa UI оборвал подписку по пятиминутной тишине во время работы
автора5b3ff237. Backend продолжил исполнение; тишина не доказывает остановку задачи.

## Решение

Предел до первого heartbeat увеличивается5→10мин, предел тишины работы15→30мин,
окно потери heartbeat60→120с. При отсутствии данных UI переподписывается на существующий
run_id через штатный догон; не предлагает повторно запускать исходный запрос. Heartbeat
продлевает только связь, реальные события — также работу. Потолок автодогонов сохраняется.
Кнопка Стоп и завершение прогона снимают оба таймера. Правила службы и план не меняются.

## Проверки

Vitest с fake timers: долгая работа с heartbeat не прерывается ранее30мин; heartbeat
не скрывает отсутствие прогресса; связь восстанавливается на том же run_id; disarm снимает
оба таймера. Полный frontend-набор, сборка и UI-реаттач текущего прогона.
