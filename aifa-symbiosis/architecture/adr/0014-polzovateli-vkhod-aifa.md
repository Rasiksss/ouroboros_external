# ADR-0014. Пользователи — вход AIFA; владелец передаётся заголовком

Статус: принято (владелец, решение №14)

## Контекст
С `OUROBOROS_MULTIUSER=true` ouroboros берёт владельца из `X-Ouroboros-Owner-Id`, чат — из
`X-Ouroboros-Chat-Id` и больше ничему в запросе не доверяет (`TrustedHeaderIdentity`,
`transport/browser/identity.py`): заголовки ставит доверенный посредник.

## Решение
- Посредник — служба движка. `owner_id` = `str(user.id)` пользователя AIFA (непрозрачная строка;
  администратор получает свой `owner_id`). `chat_id` = идентификатор проекта AIFA (один проект —
  один тред; ≤ 256 знаков, не отрицательное число).
- Заголовки владельца ставит один модуль службы — клиент ouroboros; больше нигде (F12).

## Следствия
Доверие держится сетью: порт ouroboros доступен только службе (ADR-0028).

## Чем проверяется
C2.1, F12.
