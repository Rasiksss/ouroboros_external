# ADR-0032. Каталоги службы AIFA, нужные её тестам, переносятся в `aifa/finengine/`

Статус: принято (владелец, 14.10.2026, вариант (а) проблемы P8 шага 01)
Дополняет: ADR-0019 (раскладка), ADR-0031 (перенос снимком)

## Контекст
ADR-0019 и `ARCHITECTURE.md` §3 называли для переноса `src/`, `tests/`, `pyproject.toml`, `web/` и
часть `docs/`. Тесты службы AIFA написаны от корня её репозитория и читают соседние каталоги.
Прогон на перенесённом дереве (шаг 01, `PROGRESS.md` P8): 519 failed + 44 errors против 99 + 11 у
полного корня AIFA. Проба с добавленными каталогами сняла всё, кроме тестов, читающих `web/` и
корневой `CLAUDE.md` AIFA.

## Решение
1. В `aifa/finengine/` с той же относительной раскладкой, что в AIFA, переносятся (снимком из
   `f4a12fc6`, ADR-0031):
   - `station-skills/` — исходники навыков станции, которые читают тесты службы;
   - `agent-workspace/` — рабочая папка агента OpenClaw (13 файлов);
   - `benchmarks/` — **без файлов, лежащих в Git LFS у AIFA** (196 JSON эталонов в
     `benchmarks/vendor/tests/test_benchmark/data/golden/*/json/`, 331 МиБ содержимого). Указатели
     LFS без LFS в этом репозитории были бы поддельными данными, а 331 МиБ обычным git — отдельное
     решение владельца (`PROGRESS.md` P12).
2. `web/` остаётся в `aifa/web/` (ADR-0019). Тесты службы, читающие исходники фронтенда, получают
   правку пути `ROOT.parent / "web"` — только пути, логика не меняется.
3. Не переносятся: `deploy/` (шаг 03, `aifa/deploy/dev/`; тесты, читающие `deploy/…`, остаются
   известными красными до шага 03 и правятся в нём), корневой `CLAUDE.md` и прочие корневые
   заметки AIFA (тест `test_claude_md_does_not_invent_faiss_work_that_is_already_done` остаётся
   известным красным — для него нет пути, который не менял бы смысл проверки).
4. Это переходное состояние, а не новая постоянная раскладка: `station-skills/` и зависящие от
   него тесты удаляются шагом 19 (ADR-0009, F10). `agent-workspace/` — вместе с ним.

## Следствия
- `ARCHITECTURE.md` §3: в дереве `aifa/finengine/` появляются `station-skills/`, `agent-workspace/`,
  `benchmarks/`; пометка «временно до шага 19» у первых двух.
- F10 (остатки OpenClaw) включается после шага 19 и считает только `aifa/` без этих каталогов.
- `benchmarks/vendor/src/finengine/` — вендорная копия пакета; проверки F2 и F10 должны её
  исключать (шаг 02).
- Базовая линия службы сравнивается с полным корнем AIFA; расхождения только из пунктов 1.3, 3.

## Чем проверяется
Прогон `pytest tests` службы против эталона (полный корень `f4a12fc6`): новых падений нет, кроме
перечисленных в пункте 3 и LFS-эталонов; `diff` перенесённых каталогов с `git archive f4a12fc6`.
