# ADR-0030. Git-база репозитория: `Rasiksss/ouroboros_external`, ветка `dev`, базовый коммит `17b3f93`

Статус: принято (владелец, 14.10.2026 — факт репозитория; сессия плана)
Заменяет: ADR-0019 в части git (тег базы `upstream/ouroboros-ec596862`, слияния из удалённого `corp`)

## Контекст
Владелец пересоздал репозиторий в `C:\Users\magom\Desktop\ouroboros` (проверено 14.10.2026):
- удалённый `origin` — `https://github.com/Rasiksss/ouroboros_external.git`; корпоративного
  удалённого (GitLab `api.sc-ci.sber.ru/GigaAgent/ouroboros`) больше нет, истории `release/1.5.1`
  (1634 коммита) в репозитории нет;
- рабочая ветка `dev` — один коммит без родителей `17b3f93` «Plan for symbios GigaAgent with AIFA»
  (14.10.2026 13:13 +0300): снимок дерева ouroboros `release/1.5.1` @ `ec596862` (1414 файлов) плюс
  `aifa-symbiosis/` (36 файлов на тот момент); запушен в `origin/dev`;
- `origin/main` — `0e327f1`, старая внешняя копия ouroboros (та, что развёрнута на dev в
  `/home/rasul/ouroboros`); с `dev` общей истории нет;
- тегов нет; хуков git нет (в `.git/hooks` только образцы) — хук `commit-msg` ouroboros
  (Jira + GitLab на `feature/*`) не установлен.

## Решение
1. **Репозиторий симбиоза** — `Rasiksss/ouroboros_external`; **основная ветка — `dev`**.
   `main` — старая внешняя копия: в `dev` не сливается, в `main` ничего не пушится.
2. **База ouroboros** — коммит `17b3f93`. Шаг 01 ставит на него локальный тег
   `base/ouroboros-1.5.1`; проверки F1 и F11 считают изменения от этого тега. Пушить тег — с
   разрешения владельца.
3. **Ветка шага** — `sym/NN-<кратко>` от актуального `dev`. Ветка шага сливается в `dev` локально
   (`git merge --no-ff`) после того, как у шага в `PROGRESS.md` ревью и UI-тест без блокеров;
   сливает следующая сессия реализации первым действием (или владелец). Push `dev` и любых веток —
   только владелец или по его явному разрешению.
4. **Обновления ouroboros** из корпоративного контура слиянием невозможны (истории нет). Если
   понадобятся — новый снимок отдельным решением (ADR) с перечнем затронутых путей; F1 на этот
   коммит — исключение по той же ADR.
5. Имена веток `feature/*` не используем, хотя хук не установлен: правило ouroboros остаётся в его
   `AGENTS.md`, и установка `pre-commit`/хуков его вернёт.

## Следствия
- `F1`, `F11`, промпты шагов 01–02 и ревью ссылаются на `base/ouroboros-1.5.1` вместо
  `upstream/ouroboros-ec596862`.
- Вопрос О5 (удалённый репозиторий и ветки) закрыт этой записью.
- Проверить, что снимок `17b3f93` побайтно равен `ec596862`, нельзя (истории нет); за эталон
  ouroboros принимается сам `17b3f93`.

## Чем проверяется
F1, F11 (от тега `base/ouroboros-1.5.1`); шаг 01 — тег указывает на `17b3f93`.
