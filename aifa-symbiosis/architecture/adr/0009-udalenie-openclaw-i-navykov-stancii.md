# ADR-0009. Навыки станции `aifa-*`, OpenClaw, MCP-сервер движка удаляются

Статус: принято (владелец, решения №9 и №25)

## Решение
Удаляются: диспетчер на OpenClaw, плагины гейтвея, навыки станции `aifa-extract`, `aifa-calc`,
`aifa-analyze`, `aifa-metric`, мост станции, MCP-сервер движка и зависимость `mcp<2`. Код — на
этапе 5; путь через OpenClaw на dev снимается после приёмки (этап 6). prod не трогается.

## Чем проверяется
F10 (поиск по репозиторию пуст), F11 (в замке службы нет `mcp`).
