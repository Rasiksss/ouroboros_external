   multipart) → запись `doc_id ↔ file_id`, `sha256` → распознавание (байты из каталога) → ход с
   документом → выдача файла через ручку → удаление в обоих местах.
2. **Файл-результат** из комнаты → каталог → `TextMessage.files[].file_id` → скачивание.
3. **История**: `GET /chat/history/{session_id}` → ouroboros → фильтр (ходы этого чата, финал корня)
   → `{role, content}`.
4. **Комната**: `sealed_room` → заголовки протокола → Workstation контура.
5. **Отказ XLS/DOC**: до обращения к каталогу, текст пользователю.
