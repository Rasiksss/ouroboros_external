## Постановка задачи
Сделать в службе задания автора и три инструмента автора так, чтобы код атома мог прийти от
подзадачи ouroboros; пока автором остаётся `atom_author.py` службы (временный переключатель),
поведение пользователя не меняется.

## Описание
- **`author_jobs`**: задание = контракт атома (после `check_request`), ход, корень, срок (600 с —
  настройка), счётчик проверок (3), счётчик отчётов (≤ 10), состояние; хранение в базе службы.
- **`aifa_move`** с атомом-кодом при `author_mode=subtask`: проверка контракта и «входов ещё нет»
  как сейчас → задание → в ответе `АВТОР job=<id>` + готовый текст задания для `schedule_task`;
  шаги с ещё не созданным атомом — «не создан» (как сейчас). При `author_mode=engine` — как в
  шаге 13 (`atom_author.py`).
- **`aifa_author_brief`**: контракт, формы входов, сокращённый реальный вход (как
  `render_author_prompt` сейчас — переиспользовать; граница ADR-0025), прошлый код и ошибка при
  починке, остаток попыток, правила комнаты.
- **`aifa_author_attempt`**: событие `author_attempt` (тот же эмиттер, что `_report_author_attempt`).
- **`aifa_create_atom`**: проверка кода в разовой комнате на настоящих входах `Case` (тот же путь,
  что сейчас после ответа автора) → регистрация `eph`-атома, версия = хэш контракта и кода,
  исходник в `Case` → задание закрыто; неудача — `ОТКАЗ` с хвостом ошибки и остатком; сбой станции
  не тратит попытку; событие `author_attempt` на каждую проверку.
- **`aifa_wait`** по заданию автора: итог — атом создан / попытки исчерпаны / срок.
- **Роли** (§3.0): инструменты автора — только `task_depth ≥ 1` и `root_task_id` = корень хода;
  планировщика — только корень.
- **Временный переключатель** `Settings.author_mode = "engine" | "subtask"`, по умолчанию
  `engine`; «удаляется в шаге 19»; `PROGRESS.md` §5.
- **Плагин**: регистрация трёх инструментов; снимок схем + **предложенная** ADR (F13); бюджет F4.

## Образ целевого результата

- При `author_mode=subtask` контрактный тест на настоящем ouroboros с подставной моделью: корень
  получает `АВТОР job` → `schedule_task` → подзадача: `aifa_author_brief` → `aifa_author_attempt` →
