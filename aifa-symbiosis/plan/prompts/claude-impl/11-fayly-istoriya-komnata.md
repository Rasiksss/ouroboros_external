## Описание
- **Файлы** (`ouro_client` — HTTP каталога; `doc_store` службы):
  - загрузка документа/источника: тип XLS/DOC → отказ с текстом «Сохраните файл как XLSX/DOCX и
    загрузите снова» до обращения к каталогу (ADR-0026); иначе байты → `POST /api/files`
    (владелец — пользователь, агент — по умолчанию) → `FileInfo`; соответствие `doc_id ↔ file_id`
    и `sha256` — в базе службы (миграция);
  - распознавание читает байты через каталог; распознанный текст и разметка — по-прежнему в базе
    службы;
  - выдача (`/documents/{id}/file`, `/sources/{id}/file`) — поток из `GET /api/files/{id}/content`;
  - удаление — и в каталоге;
  - файлы-результаты (`FileArtifact` из комнаты, `out.file`) — тоже в каталог; `file_id` для
    фронтенда остаётся идентификатором службы (`TextMessage.files[].file_id`), за ним — файл
    каталога.
  - Существующие на dev файлы старого AIFA не переносим (новая система стартует пустой) — запиши.
- **История**: `GET /chat/history/{session_id}` → история ouroboros чата проекта; только сообщения
  ходов этого чата: реплика пользователя с `client_message_id = run_id` и финал корня
  (`run.root_task_id`); формат `{role, content}` прежний; чужой владелец — 404 (C1.3).
  `/dialogs` — без изменений (ADR-0011).
- **Комната**: `sealed_room.py` — `X-Workstation-Protocol: 1`, `X-Session-Create-Secret` (поле
  `Settings`, если задано), `X-Trace-Id` хода, имя сессии `aifa-eph-<16 hex>`; остальное без
  изменений (C5.1 — дописать к существующим тестам).
- **Без `mcp`**: удалить `mcp_server/` службы и зависимость `mcp` из `aifa/finengine/pyproject.toml`
  (поиск ссылок по всему репозиторию: код, Dockerfile, compose, `.md`, фронтенд — правила кода
  5.2); `uv lock`; F11 — вторая половина (в замке службы нет `mcp`).
