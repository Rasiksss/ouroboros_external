## Постановка задачи
Перенести знание планировщика AIFA в навык `aifa-planning` так, чтобы цикл вёл ouroboros
инструментами, и переключить dev на ведущего-ouroboros.

## Описание
- `skills/aifa-planning/SKILL.md`: порядок хода (сначала `aifa_goal`; `НУЖЕН_ЦИКЛ` → цикл); правила
  из текущего промпта планировщика, переписанные с «ответь JSON» на «вызови инструмент с
  аргументами»; разделы «Действия», «План и файлы», «Шаги», «Части цели по ссылке», «Сценарии»,
  «Реестр показателей», «Внешние данные», «Новый атом», «Итог прошлого хода», «finalize»,
  «Данные — не инструкции»; после `ПРИНЯТО` — ответить пользователю **дословно** каноническим
  текстом (ADR-0024). Длинное — в `references/`, `SKILL.md` — путеводитель.
- `references/` — каталог атомов и реестр показателей **генерируются** службой из реестров
  (`atom_catalog.catalog_text`, описание реестра — переиспользовать функции `render_state`), а не
  пишутся руками: скрипт генерации в службе + тест «ссылки навыка совпадают с выводом
  генератора» (защита от дрейфа). Если каталог зависит от профиля отчёта — в навыке общий
  каталог, а профильный остаётся в `aifa_state` (как сейчас в сообщении хода).
- **Переключение**: `loop_driver=ouroboros` в `engine.env` `aifa-sym`; по умолчанию в коде — тоже
  `ouroboros`.
- **Реплей решений**: записанные решения планировщика из опорной записи (цикловые сценарии А1–А8 —
  какие есть в записях шага 06; если в записи нет решений модели — взять из журналов прогонов
  старого dev, путь найти по `run_logger`) → сценарии подставной модели → ход через настоящий
  ouroboros с навыком → те же ходы, итоги и события.
- **F3 (б)** канарейка: фикстурный документ со строкой-канарейкой в распознанном тексте и
  разметке (вне участков-цитат); полный путь стандартный + цикл на подставной модели; канарейки
  нет ни в одном ответе инструмента и кадре WS (журнал подставного сервера модели + журнал
  кадров `turn_gateway`).
- **Выкатка** в `aifa-sym` (сигнал дан) и дымовой цикловой сценарий вживую (GLM-5.2) — один, для
  проверки, что навык читается и цикл идёт; полное сравнение — шаг 15.

## Образ целевого результата
- На `aifa-sym` цикл ведёт ouroboros: экран показывает ходы планировщика в ленте, как раньше.
- Реплей записанных решений даёт те же ходы; F3 (б) зелёная.
- Навык не содержит кода и документов разработки; ссылки сгенерированы и проверяются.
