# Прогресс плана симбиоза

Единый журнал выполнения плана (`README.md`). Пишут все три роли. Других журналов нет: 
`34-status.md` AIFA не дополняется, `BACKLOG.md`/`HANDOFF.md` ouroboros — не наши.

Правила ведения:
- §1 — статус каждой сессии; обновляет сессия, закончив работу.
- §3 — запись каждой сессии, новые сверху внутри шага.
- §4 — проблемы, которые решить не удалось. Строка не удаляется: при решении в неё ставится
  ссылка на решение в §5 и статус «решено».
- §5 — принятые решения по проблемам: кто решил, что, почему. Архитектурное решение —
  только ссылкой на ADR.
